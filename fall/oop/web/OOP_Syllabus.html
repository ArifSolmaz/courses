Course Description

This course teaches object-oriented design through Python. Students learn to design small classes that protect their own state, then compose them into working systems where objects collaborate through clear interfaces. Every week teaches new design tools (encapsulation, inheritance, patterns) in service of one core skill: composition — building complex systems from simple, reliable components. The course culminates in a Mechatronics Toolkit project.

Learning Outcomes

Upon successful completion of this course, the student will be able to:

  1. Design classes with proper initialization, methods, and string representations that bundle data and behavior.
  2. Implement encapsulation using property decorators and validation to create self-protecting components.
  3. Compose objects using "has-a" relationships to build complex systems from simple, reliable components.
  4. Apply inheritance and polymorphism to create interchangeable components with shared interfaces.
  5. Define abstract base classes as contracts that guarantee component compatibility in composed systems.
  6. Apply SOLID principles (SRP, OCP) to keep composed systems clean and extensible.
  7. Write unit tests to independently verify each component before integration.
  8. Organize a multi-component system using Python packages and modules with clear import paths.

Notebook Grading Criteria

  • Completeness: All exercise cells attempted and submitted via the auto-submission system
  • Correctness: Code produces expected output for given inputs
  • Code quality: Readable variable names, proper indentation, comments where appropriate
  • Problem-solving approach: Evidence of step-by-step decomposition, not just brute-force solutions

Course Policies

Attendance

Regular attendance is expected. Students who miss more than 30% of classes may be denied the right to take the final exam, per university regulations. Notebook submissions serve as an additional record of engagement.

Late Submission

Weekly notebooks must be submitted by the deadline shown in each notebook. Late submissions may receive a penalty of 10% per day, up to 3 days. After 3 days, late submissions are not accepted unless a valid excuse is provided.

Academic Honesty

All submitted work must be your own. You may discuss general approaches with classmates, but the code you submit must be written independently. The following are considered violations:

  • Copying code from another student or external source without attribution
  • Sharing your exercise solutions with other students
  • Submitting work generated entirely by AI tools without understanding and modification

AI Tool Usage

AI assistants (ChatGPT, Copilot, etc.) may be used as learning aids to understand concepts. However, you must be able to explain and modify any code you submit. Exercises are designed to build your skills progressively — bypassing them with AI defeats the purpose and will leave you unprepared for exams.
