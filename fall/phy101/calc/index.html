Score a round

Open the Google Form's response sheet, select everything (⌘A) and copy, then paste it below. Only the rows carrying the code currently shown on the Run tab are marked, so it does not matter that the sheet holds every round of the term. One attempt per student is counted — the first.

Term totals

Stored in this browser only. Export regularly: clearing site data or switching machines loses them. Student IDs are hidden by default so this tab is safe to project.

Before class

Two things to do, ideally the day before. Neither of them involves a student.

1 · Check the console

Runs every check on this machine, in this browser, with the files as they sit on disk — the challenge bank, the marking rule, the answer reader, the sheet reader, storage, the stylesheet and the window size.

2 · Walk through a round

Press rehearse on the Run tab (or the D key) and the console invents a class of twelve — some right, some caught by each trap, one blank, one answer with a comma for a decimal point, a duplicate submission and a row from another round. You get the real leaderboard from fake data, and nothing reaches the term totals.

To test the Google Form as well, run a round, submit an answer to your own form with the code on screen, then open the response sheet, copy it, and mark it here. That is the only part of the chain this page cannot check by itself.
