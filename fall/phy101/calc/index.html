Score a round

Open the Google Form's response sheet. Click the empty corner box above row 1, or press ⌘A / Ctrl+A, so the whole sheet including the heading row is selected — the headings are how the columns are identified. Copy, then paste below. Only the rows carrying the round's code are marked, so it does not matter that the sheet holds every round of the term. One attempt per student is counted — the first.

Term totals

Stored in this browser only. Export regularly: clearing site data or switching machines loses them. Student IDs are hidden by default so this tab is safe to project.

Before class

Three things. The first two take four minutes, ideally the day before; the third is done once, in week 2.

1 · Check the console

Runs every check on this machine, in this browser, with the files as they sit on disk — the challenge bank, the marking rule, whether every trap is still far enough from its answer to be unmistakable, the answer reader, the sheet reader, storage, the stylesheet, how many rounds this browser is holding, and the window size. A blue remark is information, not a fault.

2 · Walk through a round

Press rehearse on the Run tab (or the D key) and the console invents a class of twelve — some right, some caught by each trap, one blank, one answer with a comma for a decimal point, a duplicate submission and a row from another round. You get the real leaderboard from fake data, and nothing reaches the term totals.

To test the Google Form as well, run a round, submit an answer to your own form with the code on screen, then open the response sheet, copy it, and mark it here. That is the only part of the chain this page cannot check by itself.

3 · The page for the students

students.html — the rules, the points and what happens in a round, in Turkish and English, written for them. Put its link on the first slide next to the form link and you never have to explain the rules twice. Three lines at the bottom of that file set the form link and keep it in step with the two settings on the Settings tab; DAY-OF-CLASS.md says which.

Settings — live results

With an endpoint set, submissions arrive by themselves: a live count while the clock runs, and the round marks itself the moment you press REVEAL. Without one, nothing changes — you paste the sheet as before. Setup is in README §7 and takes about five minutes, once.

Treat that URL as a password. It is the key to your response sheet — anyone holding it can read a round's student numbers. It is stored in this browser only, never in the repository, and it is not on the projector unless you open this tab. If it leaks: in the script editor, Deploy → Manage deployments → Archive, then deploy again for a fresh URL.

The script hands out only the rows for the code it is asked about, and only the student number, code and answer. It refuses a request with no code, so it cannot be used to pull the whole term.

On the projector

What appears in the name column, on the round table and on the term totals.

If a student submits twice

The form cannot stop a second submission, so the console decides which one counts. Whichever you choose, it tells you afterwards how many students resubmitted.
