# Python Solution Lab - PHY101

**Worked Python solutions appear in this folder one week at a time.**

Each week the course publishes `Week_XX_Python_Solutions.ipynb` - three fully worked
problems (one L1 Basic, one L2 Intermediate, one L3 Challenge) for that week's set,
using the course workflow:

> **Diagram -> Principle -> Equation -> Predict -> Verify**

## When each week appears

A week's solutions are published **one week after that week's session**, once the problem
set has closed. Before that date the file does not exist here, and the "Open in Colab"
button on the course dashboard stays locked. Nothing is released early.

The last weeks are published by the end of term, **18 December 2026**.

## How to use them

Open the week you want from the
[course dashboard](../web/PHY101_Course_Dashboard.html) - the button becomes active on
the release date and opens the notebook straight in Google Colab.

Read the prediction before you run anything. Every solution states the problem, names the
governing principle, and gives the hand prediction to make *first*; only then does it
compute the answer and check it by a second independent route. Every cell ends in an
`assert`.

A good self-test: change one parameter at the top of a solution cell and predict the new
result before re-running. Each notebook keeps its parameters at the top and sweeps
downstream, so this works without editing anything else.
