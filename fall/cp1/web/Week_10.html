01 / The situation

Can a function be correct while its calibration is wrong for the sensor?

A teaching sensor produces 0.5 V at 0 N and 4.5 V at 100 N. Assume a linear response between these two calibration points. Build a reusable conversion and distinguish interpolation inside the calibrated range from extrapolation outside it.

Your handover

The calibration derivation, a function contract, three reference checks and an explicit treatment of extrapolation.

Start on paper. Work alone or in a pair: one person predicts, the other challenges the assumptions; swap roles halfway through. All essential data is provided. No hardware or AI account is required.

02 / Build a model

Understand what the code represents.

A function needs a contract

Define the input quantity and unit, output quantity and unit, and valid domain. This model accepts voltage in volts and returns force in newtons. The calibration is an assumption supplied for this particular teaching sensor.

Derive the conversion

Slope = (100 − 0) / (4.5 − 0.5) = 25 N/V. Subtract the 0.5 V offset before multiplying: force = (voltage − 0.5) × 25. Checking both endpoints detects a missing offset.

Return a value for the next step

print() sends text to the screen. return gives a value to the caller for checking or composition. Keep conversion and presentation separate. Our minimal function performs the arithmetic; the caller is responsible for recognizing out-of-domain inputs.

Inspect the small Python model

Read and predict first. Run this self-contained example in a new notebook cell; use the result as evidence to discuss.

def voltage_to_force(voltage_v):
    # Teaching calibration: 0.5–4.5 V corresponds to 0–100 N.
    return (voltage_v - 0.5) * 25

force_n = voltage_to_force(2.5)
print('Force (N):', force_n)
assert voltage_to_force(0.5) == 0
assert voltage_to_force(4.5) == 100

Reference output

Force (N): 50.0

03 / Predict & inspect

Try to break your first explanation.

These are prepared teaching cases, not live sensor readings or an automatic grade. Write a prediction before opening a case, then reveal the reasoning one step at a time. Explain any disagreement.

01Midpoint

2.5 V; calibration endpoints (0.5 V, 0 N), (4.5 V, 100 N)

Predict: What force should the midpoint produce?

  1. Slope = 100 / 4 = 25 N/V
  2. 2.5 − 0.5 = 2.0 V above offset
  3. 2.0 × 25 = 50 N

50 N under the linear model

The midpoint is an interpolation. It does not establish real sensor linearity.

02Offset check

0.5 V; compare correct formula with voltage × 25

Predict: Which formula respects the zero-force calibration?

  1. Correct: (0.5 − 0.5) × 25 = 0
  2. Faulty: 0.5 × 25 = 12.5
  3. Endpoint test exposes the missing offset

0 N; faulty formula reports 12.5 N

Test physically meaningful points, not only arbitrary values.

03Outside calibration

5.0 V; stated calibration ends at 4.5 V

Predict: Is the arithmetic result sufficient evidence for a force claim?

  1. Formula yields (5 − 0.5) × 25 = 112.5
  2. 5.0 V is outside the calibrated interval
  3. Linear behaviour there has not been supplied

Arithmetic: 112.5 N; unvalidated extrapolation

Report the domain issue. Rejecting or flagging is a policy decision; silently clamping would hide it.

04 / Investigate

One question. Several kinds of evidence.

  1. Draw the line through the two calibration points and derive its slope with units.
  2. Implement the function. Test both endpoints and the midpoint before formatting any output.
  3. Replace return with print in a temporary copy and inspect what the caller receives. Restore return before composition.
  4. Pass 5.0 V and describe the difference between a calculated number and a justified measurement. Write the missing domain policy.
