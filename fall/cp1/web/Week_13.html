Week 13 / Build a checkable report

Summarise a whole table at once

Treat a sensor log as one array, then confirm the picture with a number.

Last week we saved a report as a file that another person can open and check. The numbers inside that file usually form a table. Looping over every cell works, but each new question needs a new loop.

A log holds four time steps for three temperature sensors. We want the mean of each sensor, the number of readings above 24.0 °C, and a plot that shows where they happen.

Why this week's tool?

A NumPy array knows its shape. One expression applies to every element, and axis=0 collapses the rows into one value per column. A Boolean mask counts readings above a limit. matplotlib turns the same array into a picture.

By the end: Explain the shape of the array. State which axis a per-sensor mean uses. Match the count of hot readings to the points that stand out in the plot.

The idea behind the program

Shape is rows by columns

np.array(temps) turns a list of lists into an array with shape (rows, columns). a[1, 2] is row 1, column 2. a[:, 0] is the whole first column. The shape decides what an operation means, so read it before computing anything.

One operation, every element

a * 0.001 converts a whole column of millimetres to metres without a loop. np.mean(a, axis=0) collapses the rows and leaves one value per column; axis=1 leaves one per row. The loop still happens, but NumPy runs it for you.

A mask counts, a plot shows

a > 24.0 is an array of True and False with the same shape as a. Its sum is the number of readings above the limit, and a[mask] selects them. A plot makes a spike visible; the mask count is the checkable number behind the picture.

A short Python example

Read the example alongside the explanation. Run it in a new notebook cell and change one input to see how it behaves.

import numpy as np
temps = np.array([[22.1, 21.8, 22.4],
                  [22.6, 22.0, 22.9],
                  [24.5, 23.0, 24.6],
                  [25.2, 23.5, 25.3]])
print('Shape:', temps.shape)
means = temps.mean(axis=0)
print('Sensor means (C):', [f'{m:.2f}' for m in means])
hot = temps > 24.0
print('Readings above 24.0 C:', int(hot.sum()))
print('Rows with a hot reading:', np.where(hot.any(axis=1))[0].tolist())

Example output

Shape: (4, 3)
Sensor means (C): ['23.60', '22.57', '23.80']
Readings above 24.0 C: 4
Rows with a hot reading: [2, 3]

An array operation applies to every element at once

np.array(temps) stores a table with a shape of rows × columns. An expression such as a * 0.001 or a > 24.0 is applied to every element. No loop is written. A mask is an array of True/False with the same shape as the data. axis=0 collapses the rows into one value per column.

Examples and variations

Each example changes something about the same problem. Open the ones you want to explore and follow the worked explanation.

01Per-sensor mean

4 rows × 3 columns; axis=0

Question: How many values does the mean return, and what does each one describe?

  1. Shape (4, 3): 4 time steps, 3 sensors
  2. axis=0 collapses the 4 rows
  3. Result has 3 values, one per sensor

Three means: 23.60, 22.57, 23.80 °C

axis=0 removes the row axis. Using axis=1 by mistake gives four values, one per time step, and the report would describe the wrong thing.

02Mask count

Limit 24.0 °C on the same table

Question: Which cells are True, and what is the sum?

  1. Row 2: 24.5 and 24.6 pass; 23.0 does not
  2. Row 3: 25.2 and 25.3 pass; 23.5 does not
  3. True counts as 1: total 4

4 readings above the limit, in rows 2 and 3

The mask has the same shape as the table. Summing it counts; indexing with it selects. Sensor B never exceeds the limit.

03Limit at a boundary

Limit 24.5 °C with the comparison >

Question: Is 24.5 counted?

  1. 24.5 > 24.5 is False
  2. Only 24.6, 25.2 and 25.3 pass
  3. Count drops from 4 to 3

3 readings above 24.5 °C
