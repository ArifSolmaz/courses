Week 01 / 14 · Linear search and a control-loop budget

Does my loop fit in 1 ms?

15 min · Engineering question

Our mobile robot reads a batch of range sensors at 1 kHz. The cycle is 1 ms. Reading sensors and updating the motors already take 0.7 ms, leaving 0.3 ms to find the first unsafe reading.

Make an individual prediction, then compare with a partner. Write down the input, measurement unit or limit you would need to make the decision.

180 minutes · 15 min opening, 35 min paper work, 10 min break, 45 min lab, 45 min design task, 25 min exam practice and 5 min exit ticket.

35 min

Trace it on paper

[72, 48, 19, 12] cm. Stop at the first reading below 20 cm. Write the position, reading, comparison and decision for each check. Repeat with a threshold of 10 cm.

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

At 20 cm, the third reading is the first unsafe one, after three checks. At 10 cm the scan uses four checks and reports no match. With n readings the worst case uses n checks. Estimate time using the measured scan and keep a margin for variation.

Find the first unsafe reading and keep its index

A range strip reports [35, 20, 42, 18, 12] cm. Trace the search with a strict 20 cm threshold. Then trace it with a threshold of 18 cm. Keep a column for the comparison count.

Show the worked steps
  1. At 20 cm, 35, 20 and 42 all fail the strict comparison. The fourth reading, 18, passes. The Python index is 3 and the count is 4.
  2. At 18 cm, equality still fails. The fifth reading, 12, is the first hit. The index is 4 and the count is 5.
  3. A full scan can count every unsafe reading. For the first hit, continuing after a match adds work without changing the answer.

Compare the two traces. Record one boundary case and a clue that would expose a wrong result. Then take a 10-minute break.

45 min

Measure it

Predict which takes longer, first hit or no hit. Run with 100 and 1,000 readings. Record the longest observed batch-average and compare with the 0.3 ms allocation. Describe how you would check the deadline on the robot.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def first_unsafe(readings, threshold):
    for position, reading in enumerate(readings):
        if reading < threshold:
            return position
    return None


for n in (100, 1000):
    first_hit = [19] + [30] * (n - 1)
    no_hit = [30] * n
    measure(f"{n}: first hit", lambda: first_unsafe(first_hit, 20))
    measure(f"{n}: no hit", lambda: first_unsafe(no_hit, 20))

45 min

Choose a safe scan budget

An upgraded controller samples 600 readings per cycle. I/O and motor work take 0.72 ms in a 1 ms period. A target-board full scan of 200 readings took 0.08 ms. The team reserves 0.05 ms for variation.

Start individually for 10 minutes. Work with a partner for 20. Spend the last 15 comparing with another pair and revising your recommendation.

  1. Calculate the available time with and without the reserve. Predict the scan time at 600 readings using a linear model.
  2. Compute the largest whole input size that fits the model with the reserve. Check a first-hit case, a last-hit case and a no-hit case separately.
  3. Write a two-sentence release recommendation. Include what you would measure on the board and one useful response if the scan exceeds its budget.
Compare a model answer

The available time is 0.28 ms before the reserve and 0.23 ms after it. The linear estimate is 0.24 ms for 600 readings, so it misses the reserved allocation by 0.01 ms. The estimate allows 575 readings. Validate the full cycle on the target under representative load. Options include lowering sample count or moving work outside the critical path if the sensing requirement allows it.

More practice

  1. What period corresponds to 1 kHz?

    Show answer

    1/1000 s = 1 ms.

  2. If other tasks take 0.7 ms, what is left?

    Show answer

    0.3 ms.

  3. If the first reading is unsafe, how many checks?

    Show answer

    One.

  4. If there are no readings, what should this search report?

    Show answer

    No match, after zero checks. Sensor failure handling is a separate system decision.

  5. What input should you include to measure a long scan?

    Show answer

    A batch with no unsafe reading or one with the only hit at the end.
