The rule

My runs · compare the two tools

SAME PARTS. TWO TOOLS.

Which tool did less work?

Finish a round. Then try the other tool on exactly the same starting line.

One comparison checks two sizes. One slot write puts a value in one array slot. A swap uses two slot writes. Holding a part is not counted as a slot write. A wrong answer adds no algorithm work: the same step waits for you.

More experiments

Three experiments to try

  1. Same parts, two tools. Finish both. Compare the counters.
  2. Almost sorted. Which tool can use the order already there?
  3. Backwards. Watch how far each held part must travel.

You do not need to remember a formula first. Play, count, and explain what changed.
