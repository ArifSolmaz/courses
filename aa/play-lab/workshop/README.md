# Workshop progression

16 self-paced challenges, with no lesson-duration labels or enforced order.

Five topic groups each have guided practice, an independent task and a construction/peer challenge; the last task is a self-reviewed reflection. Every peer activity has a solo alternative. Game links open separately and do not sync game state. Directions identify the exact game stage and input required.

15 answer checks reuse the original rail, sorting and factory models or check specific documented states. Custom routes, input arrays, dispatch orders and collision examples are checked. Reflection text is only saved, never automatically graded; notes are optional for automatically checked tasks. Final reflection requires explicit self-review, not an automatic correctness claim.

Browser-local notebook: aa-workshop-v1. Input changes clear the recorded flag and previous feedback. The student can download plain-text notes; no upload or accounts. Storage failure leaves export available. Clearing requires an in-page confirmation.

Validation: node aa/play-lab/workshop/tasks.test.cjs
Browser QA: wrong/correct result, missing evidence, completed entry, reload persistence, editing clears status, laptop and mobile layout. Existing game source logic is not changed.
