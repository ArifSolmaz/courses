Hafta 14 · Bulmak, doğrulamak ve garanti vermek

Bütün bağlantıları hangi sensör uçlarından izlersin?

← Önce: Hafta 13 — durum ve sınırŞimdi aday bulma işiyle verilen adayı denetleme işini ayır. Sonra: dersin toplu tekrarına geç →Aynı ağda farklı amaçların neden farklı yöntemler gerektirdiğini açıkla.

Aynı yönsüz ağ: AB = 2, BC = 2, AC = 3. En çok k sensörde uç izlemeyi aç: her bağlantının en az bir ucu seçili olsun. Her sensör bir bütçe birimidir. Enerji/kablo ağırlıkları saklıdır, fakat kullanılmaz. Bu, tepe örtüsü (vertex cover) karar sorusudur.

Yerel kamera laboratuvarı farklı A–B–C–D yolunu kullanır; aşağıdaki üçgenle aynı girdi değildir.

1. Çözümlü örnek — B neden yetmiyor, A ve B neden yetiyor?

Tepe adları farklı stringler; basit yönsüz kenarların uçları tanımlıdır. Aday bir string listesidir. Arayıcı adayları boyut sırasıyla denetleyiciye verir.

from itertools import combinations

def verify_cover(vertices, edges, candidate, k):
    if type(k) is not int or k < 0 or type(candidate) is not list:
        return False
    if len(candidate) > k:
        return False
    known = set(vertices)
    if any(type(v) is not str or v not in known for v in candidate):
        return False
    chosen = set(candidate)
    if len(chosen) != len(candidate):
        return False
    return all(u in chosen or v in chosen for u, v, _ in edges)

def find_cover(vertices, edges, k):
    if type(k) is not int or k < 0:
        raise ValueError("invalid budget")
    for size in range(min(k, len(vertices)) + 1):
        for group in combinations(vertices, size):
            candidate = list(group)
            if verify_cover(vertices, edges, candidate, k):
                return candidate
    return None

vertices = ["A", "B", "C"]
edges = [("A", "B", 2), ("B", "C", 2), ("A", "C", 3)]
single_ok = verify_cover(vertices, edges, ["B"], 1)
witness = find_cover(vertices, edges, 2)

["B"] AB ve BC’yi kapsar, AC’yi açık bırakır: False. ["A","B"] her kenarı kapsar: k=2 için EVET tanığıdır. Bir başarısız aday, diğerlerini elemez; HAYIR kanıtı değildir.

2. Bir adımı sen tamamla

AB, BC, AC üçgeninde her bağlantının en az bir ucu seçili olmalı. En az kaç sensör gerekir? Korunan 2,2,3 bağlantı ağırlıkları bu soruda toplanmaz.

Önce tahminini yaz; gerekirse ipucunu aç.

İpucu

Tek sensörde karşı bağlantı açıkta kalır. İki sensörün bütün bağlantılara değdiğini denetle.

Çözüm ve gerekçe — kendi hesabından sonra aç

2 sensör. Yalnız A, BC’yi; yalnız B, AC’yi; yalnız C, AB’yi açık bırakır. A ve B ise bütün bağlantıları kapsar. Alt sınır ve geçerli seçim, minimumun 2 olduğunu gösterir.

Matematik köprüsü — hızlı denetim, büyük aday uzayı

Küme üyeliği beklenen sabit maliyetliyse denetim O(|V|+|E|+|aday|) iştir; arama en çok 2|V| altküme dener. Polinom sınıflandırması girdinin kodlanmış bit uzunluğuna göredir; ağırlığın veya bütçenin sayısal büyüklüğüne değil.

P’de karar polinom zamanda bulunur; P ⊆ NP. NP’de EVET yanıtları polinom boyutlu tanıklarla polinom zamanda denetlenir; NP “polinom olmayan” demek değildir. P ile NP’nin eşitliği hâlâ açık. Üçgendeki küçük arama, genel problem için polinom algoritma veya NP-zorluk kanıtı vermez.

Bağlantı köprüsü — indirgeme okunu ve tümleyeni ayır

S bağımsızdır ancak ve ancak V∖S bir tepe örtüsüdür: S’de kenar yoksa her kenarın en az bir ucu dışarıdadır; örtünün dışında da kenar kalamaz. Üçgende {C} bağımsız, kalan {A,B} örtüdür. Aynı çizgede, 0 ≤ q ≤ |V| için en az q bağımsız tepe ⇔ en çok |V|−q tepeli örtü. Polinom dönüşüm (G,q) → (G,|V|−q) kenarları değiştirmez. Genel Bağımsız Küme karar problemini bilinen NP-tam başlangıç problemi olarak aldığımızda bu dönüşüm Tepe Örtüsü’nün NP-zorluğunu gösterir; polinom denetleyici ise NP üyeliğini sağlar.

Yeni B’nin zorluğu için bilinen zor A ≤poly B yönü gerekir: B çözücüsü A’yı da çözer. NP-tamlık hem NP üyeliği hem zorluk kanıtı gerektirir. İndirgeme yönünü incele. Çizge tümleyeni laboratuvarı bağımsız kümeden kliğe geçer; V∖S işleminden farklıdır.

from itertools import combinations

jobs = [8, 7, 6, 5, 4]
target = 15

def verifies(indices):
    if len(set(indices)) != len(indices):
        return False
    if any(type(i) is not int or i < 0 or i >= len(jobs) for i in indices):
        return False
    return sum(jobs[i] for i in indices) == target

print("Check [0, 1]:", verifies([0, 1]))
print("Check [0, 0]:", verifies([0, 0]))
for size in range(len(jobs) + 1):
    for indices in combinations(range(len(jobs)), size):
        if verifies(indices):
            print("Valid:", indices, [jobs[i] for i in indices])
