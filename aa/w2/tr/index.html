n 10 katına çıkarsa ne olur?

10 min · Mühendislik sorusu

Robot daha yoğun bir mesafe taraması alıyor. Tek tarama her noktayı bir kez inceler. Bölüp birleştiren yöntem yaklaşık n log₂ n iş, sıralı tüm çiftleri karşılaştıran yöntem n² iş yapar. Hangisi bütçeyi önce aşabilir?

Kâğıt üzerinde izle

n = 10, 100 ve 1.000 için tabloyu doldur. n ve n² değerlerini bul, n log₂ n değerini yaklaşık hesapla. Dört noktalı bir taramayı, iki seviyeli birleştirmeyi ve köşegen dahil 4 × 4 çift tablosunu kâğıtta izle.

Önce kendi izini yaz. Sonra adımları karşılaştır ve yöntemin neden işe yaradığını üç cümleyle açıkla.

İzi karşılaştır

Tarama 4 ziyaret yapar. Birleştirme modelinde 2 seviyenin her birinde 4 öğe işlenir, yani 8 ziyaret. Çift tablosunda 16 hücre vardır. Büyük-O, girdi büyüdükçe işin nasıl arttığını anlatır. Birimler, sabitler ve donanım süreyi etkiler.

Süreyi ölç

Oranları çalıştırmadan önce tahmin et. n = 100 ve 1.000 için taramayı, birleştirmeli sıralamayı ve çift döngüyü ölç. Her yöntemin kendi oranını karşılaştır. Python sürelerinin işlem sayımıyla neden tam örtüşmeyebileceğini açıkla.

Çalıştır’a bas veya kodu Python 3’e kopyala. Çıktıdaki iki süre, beş grup ortalamasının medyanı ve en büyüğüdür. Her biri çağrı başına milisaniye cinsindendir. Gözlenen en büyük grup ortalaması tek bir çağrının üst sınırı değildir.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def scan(values):
    for value in values:
        if value < 0:
            return True
    return False


def merge_sort(values):
    if len(values) < 2:
        return values
    mid = len(values) // 2
    left = merge_sort(values[:mid])
    right = merge_sort(values[mid:])
    merged = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
    return merged + left[i:] + right[j:]


def compare_pairs(values):
    matches = 0
    for a in values:
        for b in values:
            matches += a == b
    return matches


for n in (100, 1000):
    values = list(range(n, 0, -1))
    measure(f"{n}: scan", lambda: scan(values))
    measure(f"{n}: merge", lambda: merge_sort(values), repeats=20)
    measure(f"{n}: pairs", lambda: compare_pairs(values), repeats=2)
