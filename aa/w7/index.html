1. Çözümlü örnek — satır boşalınca ne olur?

Laboratuvar [2, 5, 8] ve [1, 4, 9] ile açılır. Buradaki ayrı örnek [2, 5] ve [1, 4]: 2 ≤ 1 yanlış → 1’i yaz; 2 ≤ 4 doğru → 2’yi yaz; 5 ≤ 4 yanlış → 4’ü yaz. Sağ satır boşalır; kalan 5’i kopyala.

Sonuç [1, 2, 4, 5]: 3 anahtar karşılaştırması. Kalanı kopyalama, çıktı yazımları ve döngü koşulları sayılmaz. Çıktı sıralıdır; sıradaki minimum kalan iki baştan biridir. Girdiler sırasızsa gerekçe geçersizdir.

2. Bir adımı sen tamamla

[1, 3, 5] ve [2, 4, 6] sıralı satırlarını birleştir. Bir satır boşalınca kalanı doğrudan kopyala. Kaç anahtar karşılaştırması gerekir?

Önce tahminini yaz; gerekirse ipucunu aç.

İpucu

Öndeki adayları karşılaştır: (1,2), (3,2), (3,4), (5,4), (5,6). Çıktıya yazma ile anahtar karşılaştırmasını ayrı say.

Çözüm ve gerekçe — kendi hesabından sonra aç

5 karşılaştırma. Çıktı [1, 2, 3, 4, 5, 6]. Sol satır boşalınca kalan 6 karşılaştırılmadan kopyalanır. Altı çıktı yazımı vardır; bu başka bir sayaçtır.

Matematik köprüsü — tekrar bağıntısı neyi sayıyor?

n = 2ᵏ ve T(1) = 0 olsun. Birleştirme maliyetini n çıktı yazımı olarak modelleyince T(n) = 2T(n/2) + n = n log₂ n: log₂ n birleştirme düzeyinin her birinde n yazım. Örneğin T(8) = 24. Bu, bütün Python işlemlerinin kesin sayısı değildir. n ≥ 2 toplam elemanı birleştirmede en kötü anahtar karşılaştırması n−1’dir; aynı sayaç değildir.

3. Yeni durumda kendin karar ver

Günlükler zaten sıralıysa yeniden tümünü sıralar mısın? Eşit zamanlı iki kaydın kaynak sırası korunmalıysa bağ kuralın ne olur? Bir günlük boşken ve girdiler sırasızken kararını yeniden değerlendir.

Kendi açıklamanı denetle

Sıralı günlükleri toplam n kayıtta Θ(n) zamanda birleştir. Boşsa diğerini kopyala: sıfır anahtar karşılaştırması. Eşitlikte soldan almak, her girdinin iç sırasını ve soldan-sağa birleştirilmiş başlangıç sırasına göre kararlılığı korur; cihazlar arası gerçek geliş sırası için geliş numarasını sakla. Sırasız girdiyi önce sırala. Merge sort en kötü Θ(n log n); standart quicksort en kötü Θ(n²), farklı anahtarlarda bağımsız, eş olasılıklı rastgele pivotla beklenen Θ(n log n): beklenti her çalıştırmaya garanti değildir.

Çıkış ölçütü: karşılaştırma ile yazımı ayırıp bağıntıyı düzeylerle açıklayabiliyorsan Hafta 8’de seçim kuralını BFS’ye taşı. Takıldıysan n = 8 için üç birleştirme düzeyini yeniden izle.

def merge_sort(values):
    if len(values) <= 1:
        return values[:]
    middle = len(values) // 2
    left = merge_sort(values[:middle])
    right = merge_sort(values[middle:])
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    return result + left[i:] + right[j:]

print(merge_sort([7, 2, 5, 1]))
