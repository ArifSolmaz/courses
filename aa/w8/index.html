Measure it

Predict how long corridors and open areas change the number of expanded cells. Run BFS on the shared grid and a larger open grid. Record steps, popped cells and time. Try blocking the goal’s two neighbors.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call. The pop count includes the goal and excludes stale heap entries.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

from collections import deque
from heapq import heappop, heappush

DIRECTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]


def neighbors(grid, cell):
    row, col = cell
    for dr, dc in DIRECTIONS:
        r, c = row + dr, col + dc
        if 0 <= r < len(grid) and 0 <= c < len(grid[r]) and grid[r][c] != "#":
            yield r, c


def entry_cost(grid, cell):
    row, col = cell
    symbol = grid[row][col]
    return int(symbol) if symbol.isdigit() else 1


def result(grid, parents, goal, popped):
    path = [goal]
    while parents[path[-1]] is not None:
        path.append(parents[path[-1]])
    path.reverse()
    return len(path) - 1, sum(entry_cost(grid, cell) for cell in path[1:]), popped, path

def bfs(grid, start, goal):
    queue = deque([start])
    parents = {start: None}
    popped = 0
    while queue:
        cell = queue.popleft()
        popped += 1
        if cell == goal:
            return result(grid, parents, goal, popped)
        for neighbor in neighbors(grid, cell):
            if neighbor not in parents:
                parents[neighbor] = cell
                queue.append(neighbor)
    return None, None, popped, []

maps = [
    (('S999G', '.###.', '.....'), (0, 0), (0, 4)),
    (["." * 25] * 25, (12, 12), (12, 18)),
]

planners = [("BFS", bfs)]

for grid, start, goal in maps:
    for name, planner in planners:
        def job():
            return planner(grid, start, goal)

        moves, cost, popped, path = job()
        print(name, "-> (moves, terrain cost, popped):", (moves, cost, popped))
        print("Path:", path)
        measure(name, job, repeats=30)

Route a robot with two available exits

On rows S... / .##. / G..G, the robot may exit at either (2,0) or (2,3). All traversable moves cost one. A pallet blocks the near exit in the second scenario.

Compare a model answer

The near exit is reached in two moves. With it blocked, the far exit is reached in five by following the top row to column 3 and moving down twice. Use membership in a goal set at the pop step. An empty goal set can immediately report no route. Check the path’s move count as well as its endpoints.

  1. What goes into the initial queue?

    Show answer

    S alone, already marked visited.

  2. When do we mark a cell visited?

    Show answer

  3. What if S and G are the same cell?

    Show answer

  4. What does an empty queue mean if G has not been reached?

    Show answer

    There is no reachable route.

  5. Does the method include diagonal moves?

    Show answer
