Week 08 / 14 · Breadth-first search on an occupancy grid

What route uses the fewest moves?

10 min · Engineering question

The robot can move one cell up, right, down or left. Each move costs one step. Find a route from S to G with the fewest moves. # cells are blocked. The digits are terrain labels we will use next week.

Trace it on paper

Use the grid below. Start a FIFO with S, mark cells when enqueued and record each cell’s parent. Expand neighbors in up, right, down, left order. Write the queue after each pop until G is popped. Follow parents back to S.

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

From S, the top neighbor at (0,1) and the lower neighbor at (1,0) both enter at distance 1. The FIFO expands distance layers in order. G at (0,4) is reached across the top in four moves. The queue, visited cells and parents use space proportional to the reachable cells.

Measure it

Predict how long corridors and open areas change the number of expanded cells. Run BFS on the shared grid and a larger open grid. Record steps, popped cells and time. Try blocking the goal’s two neighbors.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call. The pop count includes the goal and excludes stale heap entries.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

from collections import deque
from heapq import heappop, heappush

DIRECTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]


def neighbors(grid, cell):
    row, col = cell
    for dr, dc in DIRECTIONS:
        r, c = row + dr, col + dc
        if 0 <= r < len(grid) and 0 <= c < len(grid[r]) and grid[r][c] != "#":
            yield r, c


def entry_cost(grid, cell):
    row, col = cell
    symbol = grid[row][col]
    return int(symbol) if symbol.isdigit() else 1


def result(grid, parents, goal, popped):
    path = [goal]
    while parents[path[-1]] is not None:
        path.append(parents[path[-1]])
    path.reverse()
    return len(path) - 1, sum(entry_cost(grid, cell) for cell in path[1:]), popped, path

def bfs(grid, start, goal):
    queue = deque([start])
    parents = {start: None}
    popped = 0
    while queue:
        cell = queue.popleft()
        popped += 1
        if cell == goal:
            return result(grid, parents, goal, popped)
        for neighbor in neighbors(grid, cell):
            if neighbor not in parents:
                parents[neighbor] = cell
                queue.append(neighbor)
    return None, None, popped, []

maps = [
    (('S999G', '.###.', '.....'), (0, 0), (0, 4)),
    (["." * 25] * 25, (12, 12), (12, 18)),
]

planners = [("BFS", bfs)]

for grid, start, goal in maps:
    for name, planner in planners:
        def job():
            return planner(grid, start, goal)

        moves, cost, popped, path = job()
        print(name, "-> (moves, terrain cost, popped):", (moves, cost, popped))
        print("Path:", path)
        measure(name, job, repeats=30)

Exam-style questions

  1. What are the first two cells enqueued after S?

    Show answer

    (0,1), then (1,0).

  2. How do parents give the route?

    Show answer

    Follow them from G to S, then reverse.

  3. What if some moves cost nine units?

    Show answer

    BFS still minimizes steps. Compare weighted cost with Dijkstra.

More practice

  1. What goes into the initial queue?

    Show answer

    S alone, already marked visited.

  2. When do we mark a cell visited?

    Show answer

    When it is enqueued, to prevent duplicate entries.

  3. What if S and G are the same cell?

    Show answer

    Zero moves.

  4. What does an empty queue mean if G has not been reached?

    Show answer

    There is no reachable route.

  5. Does the method include diagonal moves?

    Show answer

    Only if the graph allows them. This map uses four neighbors.
