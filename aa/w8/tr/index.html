En az hamleli rota hangisi?

10 min · Mühendislik sorusu

Robot bir hücre yukarı, sağa, aşağı veya sola gidebilir. Her hamle bir adımdır. S’den G’ye en az adımlı rotayı bul. # hücreleri kapalıdır. Sayılar gelecek hafta kullanılacak arazi etiketleridir.

Kâğıt üzerinde izle

Aşağıdaki haritayı kullan. FIFO kuyruğuna S’yi koy. Hücreleri kuyruğa alırken işaretle ve ebeveynlerini yaz. Komşu sırası yukarı, sağ, aşağı, sol. G kuyruktan çıkana dek her çıkarma sonrası kuyruğu yaz. Ebeveynlerle S’ye dön.

Önce kendi izini yaz. Sonra adımları karşılaştır ve yöntemin neden işe yaradığını üç cümleyle açıkla.

İzi karşılaştır

S’den (0,1) ve (1,0) uzaklık 1 ile kuyruğa girer. FIFO uzaklık katmanlarını sırayla işler. (0,4) konumundaki G’ye üst sıradan dört hamlede varılır. Kuyruk, işaretler ve ebeveynler erişilebilir hücre sayısıyla orantılı yer kaplar.

Süreyi ölç

Koridor ve açık alanların genişletilen hücre sayısını nasıl değiştireceğini tahmin et. Ortak haritada ve büyük açık haritada BFS çalıştır. Hamle, kuyruktan çıkan hücre ve süreyi yaz. Hedefin iki komşusunu kapatıp dene.

Çalıştır’a bas veya kodu Python 3’e kopyala. Çıktıdaki iki süre, beş grup ortalamasının medyanı ve en büyüğüdür. Her biri çağrı başına milisaniye cinsindendir. Gözlenen en büyük grup ortalaması tek bir çağrının üst sınırı değildir. Çıkarma sayısı hedefi içerir ve öbekteki eski kayıtları saymaz.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

from collections import deque
from heapq import heappop, heappush

DIRECTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]


def neighbors(grid, cell):
    row, col = cell
    for dr, dc in DIRECTIONS:
        r, c = row + dr, col + dc
        if 0 <= r < len(grid) and 0 <= c < len(grid[r]) and grid[r][c] != "#":
            yield r, c


def entry_cost(grid, cell):
    row, col = cell
    symbol = grid[row][col]
    return int(symbol) if symbol.isdigit() else 1


def result(grid, parents, goal, popped):
    path = [goal]
    while parents[path[-1]] is not None:
        path.append(parents[path[-1]])
    path.reverse()
    return len(path) - 1, sum(entry_cost(grid, cell) for cell in path[1:]), popped, path

def bfs(grid, start, goal):
    queue = deque([start])
    parents = {start: None}
    popped = 0
    while queue:
        cell = queue.popleft()
        popped += 1
        if cell == goal:
            return result(grid, parents, goal, popped)
        for neighbor in neighbors(grid, cell):
            if neighbor not in parents:
                parents[neighbor] = cell
                queue.append(neighbor)
    return None, None, popped, []

maps = [
    (('S999G', '.###.', '.....'), (0, 0), (0, 4)),
    (["." * 25] * 25, (12, 12), (12, 18)),
]

planners = [("BFS", bfs)]

for grid, start, goal in maps:
    for name, planner in planners:
        def job():
            return planner(grid, start, goal)

        moves, cost, popped, path = job()
        print(name, "-> (moves, terrain cost, popped):", (moves, cost, popped))
        print("Path:", path)
        measure(name, job, repeats=30)

Sınav tipi sorular

  1. S’den sonra hangi iki hücre kuyruğa girer?

    Yanıtı göster

    Önce (0,1), sonra (1,0).

  2. Ebeveynler rotayı nasıl verir?

    Yanıtı göster

    G’den S’ye izle, sonra sırayı ters çevir.

  3. Bazı hamleler dokuz birim tutarsa?

    Yanıtı göster

    BFS hamleyi en aza indirir. Ağırlıklı maliyeti Dijkstra ile karşılaştır.

Ek alıştırmalar

  1. Başlangıç kuyruğunda ne var?

    Yanıtı göster

    Yalnızca ziyaret edildi olarak işaretlenmiş S.

  2. Hücreyi ne zaman ziyaret edildi olarak işaretlersin?

    Yanıtı göster

    Kuyruğa alırken. Böylece tekrar eklenmez.

  3. S ile G aynı hücreyse?

    Yanıtı göster

    Sıfır hamle.

  4. G’ye ulaşmadan kuyruk boşalırsa?

    Yanıtı göster

    Erişilebilir rota yoktur.

  5. Çapraz hamleye izin var mı?

    Yanıtı göster

    Yalnızca graf buna izin verirse. Burada dört komşu kullanılır.
