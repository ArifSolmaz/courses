0.1 Büyüme oranı ve en kötü durum (Hafta 2)

Tekrar · Hafta 2 RAM modeli: sabit boyutlu temel işlem (toplama, karşılaştırma, atama, dizi elemanı okuma) 1 birim. O = üst sınır (tavan benzetmesi), Ω = alt sınır (taban benzetmesi), Θ = sıkı sınır. Pratikte: en hızlı büyüyen terimi tut, sabiti at; 5n² + 3n = Θ(n²).
En kötü durum bir garanti verir. 1 ms bütçeli bir kontrol döngüsünde “ortalamada sığıyor” yetmez, her turda sığmalıdır (WCET). Bu hafta aynı soruyu “tek bir ekleme pahalı olabilir, ama hepsini toplayınca?” biçiminde tekrar soracağız (amortize analiz, Blok 3).
Lecture §0.1

How much work grows?

O(1): the work stays bounded as the collection grows. O(n): the work can grow in proportion to the number of items. O(log n): think of repeatedly halving the problem.

O is an upper bound; Θ describes a tight growth rate. A worst-case bound covers even the most expensive case.

0.2 Toplamlar ve yarılama (Hafta 3)

Tekrar · Hafta 3 Geometrik toplam: 1 + 2 + 4 + … + 2ᵏ = 2ᵏ⁺¹ − 1 (toplam, son terimin yaklaşık iki katıdır). Tersi: n + n/2 + n/4 + … + 1 < 2n.
Üçgen toplam: 1 + 2 + … + n = n(n+1)/2 = Θ(n²).
Logaritma: n’yi yarıya böle böle 1’e inmek ≈ lg n adım; 1’den başlayıp ikiye katlayarak n’ye çıkmak da ≈ lg n adım.

Lecture §0.2

Doubling and halving

Double the numbers: 1 + 2 + 4 + 8 = 15. Their total is less than twice the last number.

This is why occasionally copying a growing array can still be efficient overall. Halving works in reverse: 8 → 4 → 2 → 1 takes three steps.

0.3 Kaydırma ve ikili arama (Hafta 3)

Tekrar · Hafta 3 Insertion sort yeni elemanı sıralı kısımda sola kaydırarak yerine koyar; ters sıralı n elemanda n(n−1)/2 kaydırma yapar. Bu “yer açmak için komşuları teker teker oynatmak” işi bu hafta bir dizide eklemenin maliyeti olarak geri dönecek.
İkili arama: sıralı dizide en kötü ⌊lg n⌋ + 1 karşılaştırma (n = 1000 için 10). Döngü değişmezi: başlangıç + adım + bitiş; yığın ve kuyruk gibi yapılarda da “her işlemden sonra doğru kalan cümle”yi arayacağız.
Lecture §0.3

Finding a place is not making room

Binary search finds a place in a sorted array by discarding half the possibilities each step.

Shifting moves existing items to make room. Finding the place quickly does not make those moves disappear.

A loop invariant is a statement that stays true after every iteration.

Lecture §1.1

The rule and the mechanism

A queue promises: first arrival leaves first. That is its rule.

Building it with an array or linked nodes is its implementation. Like a robot: first specify what it must do, then choose the mechanism.

Lecture §1.3

Make room by moving items

Before: [2, 5, 7, _]
After:  [8, 2, 5, 7]

To add 8 at the front, all three old items move right. With n items, n move: Θ(n).

At the end, spare capacity lets us write directly into an empty slot: O(1).

Lecture §1.4

Order helps searching

Sorted: binary search is quick, but insertion must preserve order by shifting items.

Unsorted: searching may inspect everything, but appending is easy when space exists.

If order does not matter and the deletion position is known, replace that item with the last item.

2.1 İşaretçi (pointer) ve düğüm (node)

Sezgi. İşaretçi bellekteki bir yerin adresidir. Cep telefonu numarası gibi düşünün: numara bir kişiyi işaret eder ve kişi nereye giderse gitsin çalışmaya devam eder. Özel bir değer, NULL (Python’da None), “hiçbir yeri göstermiyor” demektir ve zincirin sonunu işaretler.

Bağlı liste, her biri bir veri ve sonraki düğümün işaretçisini taşıyan düğümler zinciridir. Listeye baş (head) işaretçisiyle girilir.

class Node:
    def __init__(self, item, next=None):
        self.item = item      # veri
        self.next = next      # sonraki düğüm (ya da None)

# 7 -> 3 -> 9 -> None
head = Node(7, Node(3, Node(9)))

def degerler(head):
    sonuc = []
    while head is not None:
        sonuc.append(head.item)
        head = head.next
    return sonuc

print("Liste:", degerler(head))
Lecture §2.1

Follow the arrows

7 → 3 → 9 → None

Each node holds a value and a link to the next node. head identifies the first node; None ends the chain.

To reach the third node, follow the first two links.

2.2 Üç temel işlem

Kural 4 — tek bağlı listede işlemler Arama: baştan başla; düğüm None ise yok; aradığın ise bitti; değilse next’e geç. Düğümler tek tek gezilir: O(n).
Ekleme (başa): yeni düğümün next’ini eski başa yönlendir, sonra head’i yeni düğüme çevir. İki işaretçi değişimi: O(1). Sıra önemli.
Silme: x’i silmek için öncülü (predecessor) bulmalısın, çünkü onun next’i x’i atlayacak. Öncülü bulmak bir arama (O(n)); bağlantıyı değiştirmek O(1). x baş ise öncül yoktur; head değiştirilir.
class Node:
    def __init__(self, item, next=None):
        self.item = item
        self.next = next

def degerler(head):
    sonuc = []
    while head is not None:
        sonuc.append(head.item)
        head = head.next
    return sonuc

def ara(head, k):
    p = head
    while p is not None and p.item != k:
        p = p.next
    return p                     # bulunduysa düğüm, yoksa None

def basa_ekle(head, x):
    yeni = Node(x)
    yeni.next = head             # 1) önce yeni düğüm eski listeyi göstersin
    return yeni                  # 2) sonra baş yeni düğüm olsun

def sil(head, k):
    if head is None: return None
    if head.item == k: return head.next          # baş siliniyor
    p = head
    while p.next is not None and p.next.item != k:
        p = p.next               # p = öncül
    if p.next is not None:
        p.next = p.next.next     # x'i atla
    return head

Lecture §2.4

One neighbor or two?

A singly linked node knows its next neighbor. A doubly linked node knows both neighbors.

If you already have a node in a doubly linked list, removing it takes O(1). The extra link uses memory.

The copy-next shortcut shown in the notes changes a node’s value; it cannot remove the tail and does not preserve node identity.

3.2 Toplam kopyalama: toplama yöntemi (aggregate method)

Tek bir append, dizi doluyken n kopyalama gerektirir. Ama n append’in toplamı n²’den çok daha azdır. Toplama yöntemi: işlem dizisinin toplam maliyetini bul, işlem sayısına böl.

Çözümlü örnek 5 — kapasite 1’den başla, n = 8 eleman ekle (iki katlama).
Yazmalar: 8. Kopyalamalar: dizi 2., 3., 5. append’ten önce doludur → 1 + 2 + 4 = 7 (bir sonraki, 9. append’te 8 olurdu, ama 8 elemanla bitiyoruz). Toplam = 8 + 7 = 15 < 3·8.
Kural 6 — iki katlama neden O(1) amortize? Son kopyalama dolu olan C kapasiteli diziyi taşır (C < n), ondan önceki C/2, ondan önceki C/4, … eleman kopyalar: kopyalar bir geometrik seridir (Hafta 3!): C + C/2 + C/4 + … < 2C < 2n. Yani toplam kopyalama < 2n (n’den az olduğu her n için doğru değildir: n = 5’te 1 + 2 + 4 = 7 kopya vardır). n yazma da eklenirse n append için toplam iş < 3n olur → append başına ≤ 3 = O(1) amortize.
Toplam kopyalama 2n’den az olduğundan, eleman başına düşen kopyalama sayısı 2’den azdır. Bu bir işlem dizisi üzerindeki sınırdır; her elemanın tam iki kez taşındığı anlamına gelmez.

Why not add ten slots each time?

Adding ten slots repeatedly causes copies of 10 + 20 + 30 + … items. Large copies happen too often.

3.4 Muhasebe yöntemi (accounting method): yığında çoklu-pop

Not: sınavda çıkabilir (“Core · examinable”), ama sezgisi önemlidir; formüle takılmayın.

Sezgi. Her işleme sabit bir fiyat biçersiniz. Fiyatın fazlası bir kredi (jeton) olarak veri yapısının üzerinde saklanır; sonra pahalı bir işlem geldiğinde bu jetonlarla ödenir. Kural: kredi hiç eksiye düşmez → gerçek maliyet ≤ toplam fiyat.

Yığında push, pop ve multipop(k) (en çok k eleman çıkar) olsun. Tek bir multipop n’ye kadar maliyetli olabilir. Fiyatlar: push = 2 (1’i push’un kendisi, 1’i eleman üzerinde jeton), pop = 0, multipop = 0 (her çıkan eleman kendi jetonuyla öder). Her elemanın üstünde tam bir jeton var, jeton eksiye düşemez; bir eleman iki kez çıkarılamaz.

Lecture §3.4

Pay now for removal later

Imagine each stack insertion pays two coins: one for inserting the item, one saved on it for removal.

Removing many items together looks expensive, but each already carries its removal coin. An item can be removed only once.

Starting empty, this bounds the total work of n push/pop/multipop operations by O(n).

3.5 Amortize O(1) ≠ en kötü O(1) ≠ ortalama

Kural 8 — üç ayrı kavram En kötü durumda O(1): her tek çağrı sabit zamanda biter (dizi indeksleme).
Amortize O(1): boş yapıdan başlayan herhangi bir n çağrılık işlem dizisi toplamda O(n) sürer; içindeki tek bir çağrı yavaş olabilir (dinamik dizide append: tek çağrı Θ(n)).

5.2 Halka tampon (ring / circular buffer)

Sezgi. Yuvarlak bir sushi bandı: önüne gelen tabağı alırsınız, banda yeni tabak koyan şef bir sonraki boş yere koyar; ucu yok, tur atar. Dizide bunu indeksleri “saran” bir mod işlemiyle yaparız: tail = (tail + 1) mod N.

  2. Kuyruk (BFS) seçip yeniden ilerleyin. B, C’den önce çıkar; yakın katman işlenmeden daha uzaktakiler öne geçmez. Sıra A, B, C, D, E, F olur.
  3. Bir düğüm birden fazla yoldan bekleme yapısına girmiş olabilir. Daha önce ziyaret edilmiş bir düğüm çıkarılırsa tekrar ziyaret edilmez; böyle bir adım listeye yeni harf eklemeyebilir.

Lecture §5.4

Deep first or nearby first?

A stack supports exploring deeply before returning: DFS.

A queue supports exploring nearby vertices before farther ones: BFS.

The waiting structure determines which vertex is processed next. Neighbor order also affects the exact visit sequence.

6.2 Mühendislik uygulaması: kesme (interrupt) ile örneklenen sensör verisi

Bir kesme (interrupt) bir sensörü örnekler; ana döngü örnekleri daha sonra tüketir. Üretici ile tüketici arasında örnekleri sırada tutan bir kuyruk gerekir. Halka tampon: sabit N gözlü dizi, mod N saran head/tail indeksleri. Push ve pop O(1), bellek önceden ayrılmış ve kapasite sabit, kesmenin içinde ayırıcı çağrısı yok. Bağlı liste de uçlarda O(1) çalışır ama her düğüm en az bir ek işaretçi taşır (hesaplayıcıdaki 4 bayt yalnızca örnek varsayımdır; 64-bit sistemlerde işaretçi çoğunlukla 8 bayttır) ve ayırıcı ister; genel amaçlı bellek ayırıcısı için sabit süre garantisi yoktur, dinamik bellek alanı (heap) parçalanabilir. Keep sensor readings until needed

An interrupt produces readings; the main program processes them later.

A preallocated ring buffer keeps them in order using fixed storage, without allocating a node for each reading.

Choose a full-buffer policy and check that the implementation meets the system’s timing requirements.

7.2 Yazılı alıştırmalar (cevaplar tıklayınca açılır)

A1 (kolay). Dizi mi bağlı liste mi i. elemana O(1)’de erişir? Hangilerinin kapasitesi ihtiyaç oldukça artırılabilir?

Dizi: adres = başlangıç + i × boyut, O(1). Bağlı liste i. elemana gitmek için i işaretçi izler: O(i). Hem bağlı listeler hem dinamik diziler bellek sınırına kadar büyüyebilir; yalnızca sabit boyutlu dizinin kapasitesi baştan belirlidir. Python list bir dinamik dizidir.

A2 (kolay). Yığına 1, 2, 3 push, iki kez pop: ne çıkar? Kuyruğa 1, 2, 3 enqueue, iki kez dequeue?

Yığın: 3 sonra 2 (LIFO). Kuyruk: 1 sonra 2 (FIFO).

A3 (kolay). DFS ve BFS için hangi veri yapıları kullanılır?

Yığın → DFS; kuyruk → BFS. Bu örnekte fark, bekleyen düğümlerin işlenme sırasıdır: yığın son ekleneni, kuyruk ilk ekleneni çıkarır.

A4 (kolay). Kapasite 1’den başlayıp dolunca ikiye katlayan bir dizi 1 000 eleman tutmadan önce kaç kez katlanır?

10 kez, çünkü 2¹⁰ = 1 024 ≥ 1 000 (genel: ⌈lg n⌉).

A5 (kolay). Gözcü (sentinel) nedir, ne kazandırır?

Yapının sınırına konan, hiç silinmeyen sahte eleman (örn. listenin başında sahte düğüm ya da artan sıralama için anahtarı −∞ olan eleman). Boş liste / baş düğümü / uçtan taşma gibi özel durum sınamalarını ortadan kaldırır; Büyük-O’yu değiştirmez.

A6 (kolay). [2, 5, 7, 9] dizisinde 6’yı sıralı kalacak şekilde ekleyin. Kaç eleman kayar? 5’i silerseniz kaç eleman kayar?

6, 5’ten sonra ve 7’den önce girer (konum 2): 7 ve 9 birer sağa kayar → 2 taşıma, sonuç [2, 5, 6, 7, 9]. Sonra 5’i (konum 1) silmek için 6, 7, 9 sola kayar → 3 taşıma: [2, 6, 7, 9].

A7 (orta). Kapasite 4’ten başlayıp dolunca ikiye katlayan dizide 20 append kaç kopyalama yapar? Amortize maliyet kaçtır? En pahalı tek çağrı?

Kopyalar 5., 9., 17. append’ten önce: 4 + 8 + 16 = 28. Yazma 20; toplam 48; amortize 48/20 = 2,4. En pahalı çağrı 17.: 16 kopya + 1 yazma = 17 → en kötü tek çağrı Θ(n), amortize O(1). Genel: kopyalar < 2n, yazmalar n → toplam < 3n.

A8 (orta). Dizi dolunca 10 göz ekleniyorsa n = 1 000 append’in (kapasite 10’dan başlayarak) kopya sayısı kaçtır? İki katlama ile karşılaştırın.

+10: dizi 11., 21., …, 991. append’ten önce dolu → kopyalar 10, 20, …, 990 = 10·(1+2+…+99) = 10·4950 = 49 500 (≈ n²/20). İki katlama (10 → 20 → … → 1280): kopyalar 10 + 20 + 40 + 80 + 160 + 320 + 640 = 1 270. Sabit artış Θ(n²), çarpımsal artış Θ(n).

A9 (orta). İki yığınla kuyruk: enq 1, enq 2, enq 3, deq, enq 4, deq. Her adımda In ve Out nedir? Çıkanlar?

enq 1,2,3 → In = [1,2,3] (alt→tepe), Out = []. deq: Out boş → In’i boşalt: 3, 2, 1 pop edilip Out’a push (Out = [3,2,1], tepe 1); pop → 1. In = []. enq 4 → In = [4]. deq: Out boş değil, pop → 2. Çıkış sırası 1, 2: FIFO ✓. (Sonraki deq: 3, sonra Out boş, In = [4] boşaltılır, 4.)

A10 (orta). push, pop ve get_min hepsi O(1) olan yığını tasarlayın; 5, 3, 7 push edince iki yığın ne olur?

İkinci yığında o ana kadarki en küçük değerlerı tutun. push(x): ana yığına x; min-yığına min(x, min-yığın tepesi) (boşsa x). pop: ikisinden de pop. 5, 3, 7 → ana [5,3,7], min [5,3,3]. get_min = min-yığın tepesi = 3. 7’yi pop edince min [5,3] → hâlâ 3; 3’ü pop edince min [5] → 5.

A11 (orta). 8 gözlü halka tamponda 5, 6, 7. gözler dolu (head = 5, tail = 7). Bir örnek push, sonra bir pop. Örnek hangi göze gider? head ve tail ne olur? Sonra 256 örneklik bir halkanın belleğini hesaplayın (2 bayt örnek, her biri 2 bayt olan indeksler) ve 4 baytlık işaretçi + 8 baytlık başlıklı bağlı liste ile karşılaştırın.

Push: tail = (7+1) mod 8 = 0 → örnek 0. göze. Pop: 5. göz çıkar, head = 6. Sonuç: dolu gözler 6, 7, 0 (head = 6, tail = 0). Bellek: halka 256 × 2 = 512 + iki indeks (2 × 2 = 4) ≈ 516 bayt (veri + iki indeks; dolu/boş ayrımı için kullanılan sayaç veya bayrak ve hizalama hariç), kapasite sabit. Liste: (2 + 4 + 8) = 14 bayt/düğüm × 256 = 3 584 bayt (≈ 7 kat), ayrıca push’ta ayırıcı çağrısı: en kötü çalışma süresi için sabit garanti yok, parçalanmayla başarısız olabilir; kesme içinde kabul edilemez.

A12 (zor, isteğe bağlı). Tek bağlı listede yalnızca x düğümüne işaretçi var (baş yok); x son düğüm değil. x’in değerini O(1)’de listeden silin. x son düğümse neden olmaz?

x.item = x.next.item; x.next = x.next.next. Liste, x’in orijinal değeri çıkmış hâliyle aynı değerleri içerir. x son düğümse kopyalanacak x.next yoktur; öncülü bulmak için baştan gezmek gerekir (O(n)).

A13 (zor, isteğe bağlı). Yığında push’a 2, pop’a 0, multipop’a 0 fiyatı biçip n işlemin ≤ 2n gerçek maliyet olduğunu muhasebe yöntemiyle gösterin. multipush(k) 2 fiyatıyla neden bozar?

Her push 2 öder: 1 kendi maliyeti için, 1 jeton elemanın üstünde. Her eleman yığında kaldığı sürece 1 jeton taşır; pop/multipop elemanı çıkarırken jetonla ödeme yapar. Kredi eksiye düşmez → gerçek maliyet ≤ toplam fiyat = 2·(push sayısı) ≤ 2n. multipush(k) k eleman ekler (gerçek maliyet k) ama 2 fiyat öderse kasa 2 − k olur (k > 2 için eksi) ve elemanların jetonları eksik kalır; doğru fiyat 2k olurdu, yani işlem sabit amortize değildir.

Şimdilik atlayabilirsiniz A12 ve A13 isteğe bağlıdır; shunting-yard kutusu da öyle. Sınav kapsamı için resmî sayfadaki kapsam listesine bakın.

The one sentence to remember

Choose the structure that makes your most important operation cheap—and state the conditions under which it is cheap.

Array: direct indexing. List: change known links. Stack: newest first. Queue: oldest first.

Amortized O(1) is a sequence guarantee, not a deadline guarantee for every call.
