Week 04 / 14 · Arrays, linked lists, ring buffers and stacks

How do I store a sensor stream?

10 min · Engineering question

A sensor produces data faster than the robot can sometimes consume it. Use a fixed-capacity FIFO to keep memory bounded. Choose a policy for overflow. Here the oldest sample is overwritten and a loss counter is incremented.

Trace it on paper

Draw three slots. Push A, B and C, pop once, then push D and E. Record head, size, and the logical FIFO order after each action. Separately push A and B onto a stack and pop once.

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

The FIFO pop returns A. D wraps into the freed slot. E overwrites B. The final FIFO is C, D, E and one sample was lost. The stack returns B. A ring uses index arithmetic on an array. A linked queue can also enqueue and dequeue in constant work with head and tail pointers, but uses links and often allocates nodes.

20 min

Measure it

Predict which grows with buffer size, shifting an array on every pop or advancing a ring index. Time repeated full-buffer push/pop cycles. Compare at both capacities and account for bytes per sample separately.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def shift_cycle(buffer):
    buffer.append(buffer.pop(0))


def ring_cycle(buffer, head):
    value = buffer[head]
    buffer[head] = value
    return (head + 1) % len(buffer)


def ring_job(buffer):
    head = 0

    def step():
        nonlocal head
        head = ring_cycle(buffer, head)
    return step


for n in (128, 8192):
    shift_buffer = list(range(n))
    ring_buffer = list(range(n))
    measure(f"{n}: shift", lambda: shift_cycle(shift_buffer))
    measure(f"{n}: ring", ring_job(ring_buffer))

Exam-style questions

  1. How many samples remain after pushing four into an empty capacity-three overwrite ring?

    Show answer

    Three. One was lost.

  2. How much payload fits in 128 slots of 8 bytes?

    Show answer

    1,024 bytes, plus indices and any representation overhead.

  3. If every sample must be retained, is overwrite a fit?

    Show answer

    No. Reduce the production rate, increase throughput, or provide capacity for the worst expected burst.

More practice

  1. What does FIFO mean for timestamp order?

    Show answer

    The oldest queued sample comes out first.

  2. What does a stack pop after pushes 5, 9?

    Show answer

    9.

  3. What slot follows index 3 in a four-slot ring?

    Show answer

    Index 0.

  4. Why track size or a full flag?

    Show answer

    Equal head and tail indices can represent either a full or an empty buffer.

  5. Which representation supports direct access by index?

    Show answer

    An array gives direct indexing. A linked list generally follows links.
