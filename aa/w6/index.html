How do I filter noisy data?

15 min · Engineering question

One range reading spikes to 200 cm near a wall. A median filter uses the middle of a small window to reduce the influence of that outlier.

Make an individual prediction, then compare with a partner. Write down the input, measurement unit or limit you would need to make the decision.

35 min

Trace it on paper

Insertion-sort [12, 200, 11, 13, 10] on paper. After each insertion write the sorted prefix. Read the median. Then merge [10, 13] with [11, 12, 200].

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

The prefixes grow to [12, 200], [11, 12, 200], [11, 12, 13, 200], then [10, 11, 12, 13, 200]. The median is 12 cm. Merge sort combines sorted halves and commonly needs temporary space. Quicksort partitions around a pivot. Poor pivots can give quadratic work.

Choose a filter for spikes and real changes

Compare the mean and median of [10, 11, 12, 13, 80]. Then use sliding windows of three on the stream [10, 11, 80, 12, 13]. Trace each full window.

Show the worked steps
  1. The sum is 126 and the mean is 25.2. The median is 12, so one high spike barely affects the center of the sorted window.
  2. The three full windows are [10, 11, 80], [11, 80, 12] and [80, 12, 13]. Their medians are 11, 12 and 13.
  3. A three-sample median can delay a real change. With [10, 10, 30, 30], the two full windows output 10 and then 30.

Compare the two traces. Record one boundary case and a clue that would expose a wrong result. Then take a 10-minute break.

45 min

Measure it

Compare the insertion-sort median with Python’s sorted-based median for odd windows 5 and 31. Use the same unsorted input and include the copy needed to keep the sensor window intact.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def insertion_median(window):
    values = window.copy()
    for i in range(1, len(values)):
        key = values[i]
        j = i
        while j > 0 and values[j - 1] > key:
            values[j] = values[j - 1]
            j -= 1
        values[j] = key
    return values[len(values) // 2]


def sorted_median(window):
    return sorted(window)[len(window) // 2]


for n in (5, 31):
    window = [(13 * i + 11) % 47 for i in range(n)]
    window[1] = 200
    print(n, "->", insertion_median(window))
    assert insertion_median(window) == sorted_median(window)
    measure(f"{n}: insertion", lambda: insertion_median(window))
    measure(f"{n}: sorted", lambda: sorted_median(window))

Filter a dock sensor without hiding a real movement

A sensor reports [20, 21, 90, 22, 23, 40, 41, 42]. The 90 is a spike, and the last three readings are a real step. Compare a trailing median of width 3 with one of width 5.

Start individually for 10 minutes. Work with a partner for 20. Spend the last 15 comparing with another pair and revising your recommendation.

  1. Write the first full window and output for each width. Continue until the stream ends, recording the original sample index beside each output.
  2. For each width, find the first full-window output of at least 40. Compare it with the sample where the step starts.
  3. Recommend a width if detecting the step within one extra sample is a requirement. Explain what other disturbances you would test.
Compare a model answer

Width 3 gives 21, 22, 23, 23, 40, 41. Width 5 gives 22, 23, 40, 40. The step starts at sample 6. Both first reach 40 at sample 7 in this stream because the high spike is still in the width-5 window. Without the spike, width 5 can lag by two samples. Test clean steps as well as mixtures of noise and steps.

Exam-style questions

Spend 15 minutes on the three questions and two of the extra drills without help. Use the last 10 to check answers and rewrite one explanation.

  1. Insert 4 into the sorted prefix [2, 6, 8].

    Show answer

    [2, 4, 6, 8]. Shift 8 and 6.

  2. How can bad quicksort pivots cost more?

    Show answer

    Each partition can leave almost all items for the next partition.

  3. Why might a larger median window be undesirable?

    Show answer

    It adds computation and can delay the response to a real change.

More practice

  1. What is the median of [3, 90, 5]?

    Show answer

    5.

  2. Merge [1, 7] and [2, 4].

    Show answer

    [1, 2, 4, 7].

  3. What happens when insertion sort receives an already sorted window?

    Show answer

    Each item stays in place, with roughly one comparison per insertion.

  4. What is the median of five identical readings?

    Show answer

    That same reading.

  5. Why keep an odd window for this activity?

    Show answer

    There is a single middle position.
