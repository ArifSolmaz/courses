Before you start

Python indexes start at 0. In [lo, hi), lo is included and hi is excluded.

Binary search needs sorted data. If the middle entry is below the key, every entry to its left is below the key too. Discard those entries and the middle. Otherwise the middle might be the first acceptable entry, so use its position as the new upper boundary.

The interval shrinks until the boundaries meet. The result is a position, so a caller that needs an exact match must check the value there. Roughly halving the interval gives logarithmic work. Consecutive loops add their counts, while a full inner loop for each outer step multiplies them.

There are two equal entries, but this rule returns the first one. A key of 50 would return 5. Check the returned index before looking up its value or interpolating.

Trace it on paper

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

The inspected indices are 4, 2, 3 and the insertion index is 3. Each comparison discards roughly half the remaining candidate elements. A loop that scans n rows and m columns uses n × m visits. Two successive scans use n + m.

Compare a three-sentence explanation

For 430 the first midpoint is 4, so set hi to 4. Index 2 is too small, so move lo to 3. Index 3 is acceptable, so hi becomes 3 and the search returns 3.

Trace a lower bound with duplicate keys

Use the sorted ADC values [120, 220, 220, 450, 720]. Find the first index whose value is at least 220, then repeat for 221 and 900. Record lo, hi, mid and the comparison.

Show the worked steps
  1. For 220, inspect indices 2, 1 and 0. When the middle value equals the key, move hi left. The result is index 1.
  2. For 221, inspect indices 2, 4 and 3. Index 3 is the first value greater than the key.
  3. For 900, the interval ends at index 5. That index is a valid insertion position beyond the last value. Check it before reading a table entry.

Compare the two traces. Record one boundary case and a clue that would expose a wrong result. Then take a 10-minute break.

Common mistakes

  • Using the same update for < and =.
  • Reading index hi when hi is the table length.
  • Applying binary search to unsorted data.

45 min

Measure it

Predict how scan and binary lookup behave as the sorted calibration table grows. Time both with the same above-maximum target, then try a first-entry hit. Keep table construction outside the measurement.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def lower_bound(values, key):
    lo, hi = 0, len(values)
    while lo < hi:
        mid = (lo + hi) // 2
        if values[mid] < key:
            lo = mid + 1
        else:
            hi = mid
    return lo

def scan_bound(values, key):
    for index, value in enumerate(values):
        if value >= key:
            return index
    return len(values)


for n in (100, 1000):
    values = list(range(n))
    for key in (n, 0):
        assert scan_bound(values, key) == lower_bound(values, key)
        measure(f"{n}/{key}: scan", lambda: scan_bound(values, key))
        measure(f"{n}/{key}: binary", lambda: lower_bound(values, key))

45 min

Build an ADC lookup contract

The calibration pairs are (100, 0°C), (200, 20°C), (400, 60°C) and (700, 90°C). The controller receives 300, 400, 90 and 850. The team must agree how to handle values outside the table.

Start individually for 10 minutes. Work with a partner for 20. Spend the last 15 comparing with another pair and revising your recommendation.

  1. Trace the lower bound for each input. For 300, use the neighboring ADC values to interpolate between the two temperatures.
  2. Specify return values for an exact key, an empty table and both out-of-range readings. Explain whether duplicate ADC keys are legal.
  3. Write four acceptance tests and decide where the cost of sorting and checking the calibration table belongs in the program.
Compare a model answer

The lower-bound indices are 2, 2, 0 and 4. At 300 the fraction between 200 and 400 is one half, so the estimate is 40°C. The exact key 400 gives 60°C. One defensible contract reports out of range for 90 and 850, and configuration error for an empty or duplicate-key table. Validate the table once when loading it.
