How do I read cost from code?

10 min · Engineering question

The robot converts thermistor ADC readings using a calibration table sorted by ADC value. Find the insertion index for a reading, then inspect the adjacent calibration entries if interpolation is needed.

Trace it on paper

Trace a binary search for 430 in [120, 220, 330, 430, 550, 680, 790, 900]. Use zero-based indices and a half-open interval [lo, hi). Inspect the middle. If its value is smaller than the target, set lo = mid + 1. Otherwise set hi = mid. Stop at lo = hi.

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

The inspected indices are 4, 2, 3 and the insertion index is 3. Each comparison discards roughly half the remaining candidate elements. A loop that scans n rows and m columns uses n × m visits. Two successive scans use n + m.

20 min

Measure it

Predict how scan and binary lookup behave as the sorted calibration table grows. Time both with the same above-maximum target, then try a first-entry hit. Keep table construction outside the measurement.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def lower_bound(values, key):
    lo, hi = 0, len(values)
    while lo < hi:
        mid = (lo + hi) // 2
        if values[mid] < key:
            lo = mid + 1
        else:
            hi = mid
    return lo

def scan_bound(values, key):
    for index, value in enumerate(values):
        if value >= key:
            return index
    return len(values)


for n in (100, 1000):
    values = list(range(n))
    for key in (n, 0):
        assert scan_bound(values, key) == lower_bound(values, key)
        measure(f"{n}/{key}: scan", lambda: scan_bound(values, key))
        measure(f"{n}/{key}: binary", lambda: lower_bound(values, key))

Exam-style questions

  1. Trace the insertion index for 500 in the table.

    Show answer

    Index 4, between 430 and 550.

  2. How many visits for 12 rows and 8 columns?

    Show answer

    96.

  3. When might a scan be a better fit?

    Show answer

    For a tiny unsorted table queried once, sorting and maintaining order may cost more than scanning.

More practice

  1. Where does a target above 900 go?

    Show answer

    Index 8, after the last entry. Handle that boundary before interpolating.

  2. What index does an empty table return?

    Show answer

    0. There is no calibration pair to interpolate.

  3. A loop halves 64 until it reaches 1. How many halvings?

    Show answer

    Six.

  4. How many visits in successive scans of 12 and 8 readings?

    Show answer

    20.

  5. Will this binary search work on unsorted ADC values?

    Show answer

    The result is unreliable because the discarded half can contain the correct position.
