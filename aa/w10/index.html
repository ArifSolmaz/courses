Compare heuristic priorities and lower bounds

On an open 4 × 4 grid use start (0,0), goal (0,3) and unit move cost. Compare the first few pops for Dijkstra and A*. Break ties by row then column as in the starter.

Show the worked steps
  1. From S, the right and down neighbors both have g = 1. The right neighbor has h = 2 and f = 3. The down neighbor has h = 4 and f = 5.
  2. A* keeps popping along the top row and reaches the goal after four pops including S. With h = 0, Dijkstra also considers cells off that row before reaching G.

45 min

Measure it

Compare Dijkstra and A* with the same map, goal and tie rule. Predict how an open grid with the goal near the start changes the work. Log expanded cells as well as time. Try h = 0 and compare.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call. The pop count includes the goal and excludes stale heap entries.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

from collections import deque
from heapq import heappop, heappush

DIRECTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]


def neighbors(grid, cell):
    row, col = cell
    for dr, dc in DIRECTIONS:
        r, c = row + dr, col + dc
        if 0 <= r < len(grid) and 0 <= c < len(grid[r]) and grid[r][c] != "#":
            yield r, c


def entry_cost(grid, cell):
    row, col = cell
    symbol = grid[row][col]
    return int(symbol) if symbol.isdigit() else 1


def result(grid, parents, goal, popped):
    path = [goal]
    while parents[path[-1]] is not None:
        path.append(parents[path[-1]])
    path.reverse()
    return len(path) - 1, sum(entry_cost(grid, cell) for cell in path[1:]), popped, path

def weighted(grid, start, goal, heuristic):
    frontier = [(heuristic(start, goal), start, 0)]
    costs = {start: 0}
    parents = {start: None}
    popped = 0
    while frontier:
        _, cell, cost = heappop(frontier)
        if cost != costs[cell]:
            continue
        popped += 1
        if cell == goal:
            return result(grid, parents, goal, popped)
        for neighbor in neighbors(grid, cell):
            candidate = cost + entry_cost(grid, neighbor)
            if candidate < costs.get(neighbor, float("inf")):
                costs[neighbor] = candidate
                parents[neighbor] = cell
                priority = candidate + heuristic(neighbor, goal)
                heappush(frontier, (priority, neighbor, candidate))
    return None, None, popped, []


def zero(cell, goal):
    return 0

def manhattan(cell, goal):
    return abs(cell[0] - goal[0]) + abs(cell[1] - goal[1])

maps = [
    (('S999G', '.###.', '.....'), (0, 0), (0, 4)),
    (["." * 25] * 25, (12, 12), (12, 18)),
]

planners = [
    ("Dijkstra", lambda grid, s, g: weighted(grid, s, g, zero)),
    ("A*", lambda grid, s, g: weighted(grid, s, g, manhattan)),
]

for grid, start, goal in maps:
    for name, planner in planners:
        def job():
            return planner(grid, start, goal)

        moves, cost, popped, path = job()
        print(name, "-> (moves, terrain cost, popped):", (moves, cost, popped))
        print("Path:", path)
        measure(name, job, repeats=30)

Audit a heuristic when the floor includes zero-cost cells

Consider rows S11G / 0000 with start (0,0) and goal (0,3). Entering G costs 1. A teammate proposes plain Manhattan distance even though some moves cost zero.

Start individually for 10 minutes. Work with a partner for 20. Spend the last 15 comparing with another pair and revising your recommendation.

Compare a model answer

The direct route costs 3 and the lower route costs 1. At the right neighbor f = 1 + 2 = 3. At the lower neighbor f = 0 + 4 = 4, although only 1 unit remains on the optimal route. The unscaled heuristic can lead to cost 3. Multiplying by minimum step cost zero makes h = 0, and Dijkstra finds cost 1.
