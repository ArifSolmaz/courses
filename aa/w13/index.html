1. Çözümlü örnek — aynı sensör, farklı adım sayısı

D[t,v], A’dan v’ye tam t bağlantıyla ulaşan yürüyüşün minimum maliyetidir. Bütün komşular tanımlı, ağırlıklar sonlu tamsayı; adım sayısı negatif olmayan tamsayıdır.

def exact_walk_cost(graph, start, target, steps):
    if type(steps) is not int or steps < 0:
        raise ValueError("invalid steps")
    if start not in graph or target not in graph:
        raise ValueError("unknown endpoint")
    infinity = float("inf")
    table = [{v: infinity for v in graph}]
    table[0][start] = 0
    for t in range(1, steps + 1):
        previous = table[t - 1]
        current = {v: infinity for v in graph}
        for u in graph:
            if previous[u] == infinity:
                continue
            for v, weight in graph[u]:
                offer = previous[u] + weight
                current[v] = min(current[v], offer)
        table.append(current)
    return table[steps][target], table

2. Bir adımı sen tamamla

Aynı yönsüz ağda AB = 2, BC = 2, AC = 3. A’dan C’ye tam 3 bağlantılı yürüyüşün en küçük toplam maliyeti kaçtır? Sensör tekrarına izin var; bir adımlı doğrudan yol bu sorunun cevabı değildir.

Önce tahminini yaz; gerekirse ipucunu aç.

İpucu

İkinci satırda D[2,A] = 4 ve D[2,B] = 5. C’ye son bağlantı A’dan 3 veya B’den 2 ekler. İki teklifi karşılaştır.

Çözüm ve gerekçe — kendi hesabından sonra aç

7 maliyet birimi. min(4+3, 5+2) = 7. A–B–A–C ve A–C–B–C bu maliyeti sağlar; çözüm sayısı olan 3’ü yazma.

Matematik köprüsü — satırın anlamından bağıntıya

Taban D[0,A]=0, diğer tepeler için ∞’dur. Geçiş D[t,v] = minu→v(D[t−1,u] + w(u,v)): son bağlantıdan önceki en iyi maliyete o bağlantıyı ekle. Uygun önceki durum yoksa sonuç ∞ kalır. Burada V sensör, E komşuluk listelerindeki toplam bağlantı kaydı sayısıdır; yönsüz bir bağlantının iki kaydı vardır. k ≥ 1 için çalışma O(k(V+E)), saklanan tablo O(kV) alandır; sabit maliyetli aritmetik varsayılır. Bu kod sıfır satırı dahil (k+1)V hücre saklar; minimum maliyet 7, işlem sayısı değildir.

3. Yeni durumda kendin karar ver

Hiç yürüyüş yoksa veya k=0 ise ne olur? Ağırlık negatifleşirse sonlu k neden Dijkstra’dan farklıdır? “Her sensör en fazla bir kez” şartında (t,v) yeterli mi?

Kendi açıklamanı denetle

Çözüm yoksa ∞; k=0 ve başlangıç=hedef ise 0, farklıysa ∞. Sonlu k’de sınırlı sayıda yürüyüş vardır; negatif ağırlıklar da bu tabloda geçerlidir. Dijkstra’nın negatif olmama koşulu buraya taşınmaz. Sensör tekrarı yasaklanırsa geçmişte ziyaret edilen küme de gerekir; (t,v) tek başına gelecekteki seçenekleri belirlemez. Küme içeren durum sayısı üstel büyüyebilir.

source = "cat"
target = "cut"
m, n = len(source), len(target)
dp = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(m + 1):
    dp[i][0] = i
for j in range(n + 1):
    dp[0][j] = j
for i in range(1, m + 1):
    for j in range(1, n + 1):
        replace_cost = 0 if source[i - 1] == target[j - 1] else 1
        dp[i][j] = min(dp[i - 1][j] + 1,
                       dp[i][j - 1] + 1,
                       dp[i - 1][j - 1] + replace_cost)
for row in dp:
    print(row)
print("Distance:", dp[m][n])
