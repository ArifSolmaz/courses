14 weeks · Algorithm Analysis for mechatronics

Will it fit the robot’s budget?

Will this computation fit in my robot’s time and memory budget, and which method should I pick?

Follow one mobile robot from its first sensor reading to its route, startup and workcell tour. Each three-hour class includes two paper cases, a Python lab with input changes, a design task, exam practice and an exit ticket. No prior Python is required.

The learning route

One question leads to the next.

Lesson languages: All 14 weeks have English and Turkish editions. Switch language inside each lesson.

  1. 01–03 · Read and measure

    Count work and estimate the budget for a control cycle.

    Week 01Does my loop fit in 1 ms?Linear search and a control-loop budget→
  2. Week 02What happens when n grows 10×?Growth shapes, counts and timing→
  3. Week 03How do I read cost from code?Loop bounds, halving and binary search→

  4. 04–07 · Store, filter and schedule

    Keep sensor data and release timers within a fixed budget.

    Week 04How do I store a sensor stream?Arrays, linked lists, ring buffers and stacks→
  5. Week 05How do I look things up fast?Sorted tables and hash lookup→
  6. Week 06How do I filter noisy data?Median windows and sorting choices→
  7. Week 07Which task runs next?Priority queues and timer heaps→

    Midterm follows Week 7.

  8. 08–11 · Route and start up

    Find a grid route, then order the robot’s startup tasks.

    Week 08What route uses the fewest moves?Breadth-first search on an occupancy grid→
  9. Week 09What route costs least over terrain?Dijkstra and terrain costs→
  10. Week 10Can we get there faster?A* and a lower bound on remaining cost→
  11. Week 11In what order do we start the robot?DFS, cycles and topological order→

  12. 12–14 · Connect, reuse and approximate

    Wire the dock, reuse route costs and plan a pickup tour.

    Week 12How do we wire the stations at minimum cost?Kruskal and spanning trees→
  13. Week 13How can I reuse work across routes?Grid dynamic programming and the Bellman idea→
  14. Week 14What if I cannot find an exact tour fast enough?Traveling salesperson, heuristics and P versus NP→
