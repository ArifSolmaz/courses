Week 09 / 14 · Dijkstra and terrain costs

What route costs least over terrain?

10 min · Engineering question

The digits now give the energy cost of entering a cell. Dots and G cost one. S starts with cost zero. The cheapest route may take more moves.

25 min

Trace it on paper

Use the same grid. Keep tentative cost and parent per cell. Pop the smallest tentative cost, breaking ties by row then column. For each legal neighbor, try current cost plus its entry cost. Update only when the candidate is smaller. Stop when G is popped with its current best cost.

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

The top route costs 9 + 9 + 9 + 1 = 28. The lower corridor reaches G in eight moves with cost 8. A settled cell has the cheapest known cost because every future extension adds a nonnegative amount. Ignore outdated heap entries when a better cost has already been stored.

20 min

Measure it

Compare BFS and Dijkstra on both maps. Record steps, terrain cost, expanded cells and time. Then make every traversable cell cost one and compare again.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call. The pop count includes the goal and excludes stale heap entries.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

from collections import deque
from heapq import heappop, heappush

DIRECTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]


def neighbors(grid, cell):
    row, col = cell
    for dr, dc in DIRECTIONS:
        r, c = row + dr, col + dc
        if 0 <= r < len(grid) and 0 <= c < len(grid[r]) and grid[r][c] != "#":
            yield r, c


def entry_cost(grid, cell):
    row, col = cell
    symbol = grid[row][col]
    return int(symbol) if symbol.isdigit() else 1


def result(grid, parents, goal, popped):
    path = [goal]
    while parents[path[-1]] is not None:
        path.append(parents[path[-1]])
    path.reverse()
    return len(path) - 1, sum(entry_cost(grid, cell) for cell in path[1:]), popped, path

def bfs(grid, start, goal):
    queue = deque([start])
    parents = {start: None}
    popped = 0
    while queue:
        cell = queue.popleft()
        popped += 1
        if cell == goal:
            return result(grid, parents, goal, popped)
        for neighbor in neighbors(grid, cell):
            if neighbor not in parents:
                parents[neighbor] = cell
                queue.append(neighbor)
    return None, None, popped, []

def weighted(grid, start, goal, heuristic):
    frontier = [(heuristic(start, goal), start, 0)]
    costs = {start: 0}
    parents = {start: None}
    popped = 0
    while frontier:
        _, cell, cost = heappop(frontier)
        if cost != costs[cell]:
            continue
        popped += 1
        if cell == goal:
            return result(grid, parents, goal, popped)
        for neighbor in neighbors(grid, cell):
            candidate = cost + entry_cost(grid, neighbor)
            if candidate < costs.get(neighbor, float("inf")):
                costs[neighbor] = candidate
                parents[neighbor] = cell
                priority = candidate + heuristic(neighbor, goal)
                heappush(frontier, (priority, neighbor, candidate))
    return None, None, popped, []


def zero(cell, goal):
    return 0

maps = [
    (('S999G', '.###.', '.....'), (0, 0), (0, 4)),
    (["." * 25] * 25, (12, 12), (12, 18)),
]

planners = [("BFS", bfs), ("Dijkstra", lambda grid, s, g: weighted(grid, s, g, zero))]

for grid, start, goal in maps:
    for name, planner in planners:
        def job():
            return planner(grid, start, goal)

        moves, cost, popped, path = job()
        print(name, "-> (moves, terrain cost, popped):", (moves, cost, popped))
        print("Path:", path)
        measure(name, job, repeats=30)

Exam-style questions

  1. Which of those two is popped first?

    Show answer

    (1,0).

  2. A cell costs 12 so far. A cost-5 cell can enter it for 3. What changes?

    Show answer

    Its cost becomes 8 and its parent becomes the cost-5 cell.

  3. Can we use this rule with negative movement costs?

    Show answer

    No. A later negative edge could improve a previously settled cost.

More practice

  1. What tentative cost starts at S?

  2. What are the first tentative neighbor costs?

    Show answer

  3. Why can G first appear in the heap before we know its optimum?

    Show answer

    A later route can improve its tentative cost. Stop on a current minimum pop.

  4. Which route has fewer moves?

    Show answer

    The top route, 4 versus 8.

  5. Which uses less energy?

    Show answer
