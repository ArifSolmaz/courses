1. Çözümlü örnek — C, D’yi görünce döngü mü var?

Yerel görselle aynı yönlü çizge; bütün komşular sözlükte anahtardır ve yazılı sırada denenir. İçteki visit çağrıları dönüş yerlerini çağrı yığınında saklar; nonlocal ortak inceleme sayacını günceller.

def dfs_dependencies(graph):
    state = {u: "white" for u in graph}
    discovery, finish, scans = [], [], 0
    def visit(u):
        nonlocal scans
        state[u] = "gray"
        discovery.append(u)
        for v in graph[u]:
            scans += 1
            if state[v] == "white":
                visit(v)
            elif state[v] == "gray":
                raise ValueError("directed cycle")
        state[u] = "black"
        finish.append(u)
    for u in graph:
        if state[u] == "white":
            visit(u)
    return discovery, finish, scans

graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
discovery, finish, scans = dfs_dependencies(graph)

Keşif A,B,D,C; bitiş D,B,C,A. C→D incelendiğinde D siyahtır: döngü kanıtı değildir. Ters bitiş A,C,B,D, her oku ileri taşıyan geçerli topolojik sıradır; tek olası sıra değildir.

2. Bir adımı sen tamamla

A→B, A→C, B→D, C→D okları olan yönlü çizgede tüm DFS tamamlanınca kaç yönlü kenar incelenir? C → D, D bitmiş olsa da sayılır. Giriş/çıkışları ve renk atamalarını bu sayaca katma.

3. Yeni durumda kendin karar ver

D→A eklenirse hangi durum hatayı kanıtlar? Bağlantısız bir görev, iki yönlü fiziksel bağlantı veya en az bağlantılı yol istendiğinde aynı kararı kullanabilir misin?

Kendi açıklamanı denetle

D’den A’ya bakarken A gridir: A→B→D→A döngüsü vardır; topolojik sıra yoktur. Topolojik sıralama yalnız yönlü döngüsüz çizgede (DAG) mümkündür. Dış döngü bağlantısız görevleri de kapsar. Bu kod yönlüdür; basit yönsüz çizgede ebeveyne dönüş kenarı döngü sayılmamalıdır. DFS en az kenarlı yolu garanti etmez; bunun için BFS’ye dön.

Komşuluk listeleriyle tam DFS O(V + E)’dir; renkler ve çağrı yığını O(V) ek yer kullanır. Çok derin bir çizgede Python’un özyineleme sınırına dikkat et; açık yığın kullanılabilir. Mevcut Python laboratuvarı aynı bağımlılık problemini DFS yerine giriş dereceleriyle Kahn algoritması kullanarak çözer.

from collections import deque

graph = {"A": ["B", "C"], "B": ["D"],
         "C": ["D", "E"], "D": ["E"], "E": []}
indegree = {u: 0 for u in graph}
for u in graph:
    for v in graph[u]:
        indegree[v] += 1
ready = deque(u for u in graph if indegree[u] == 0)
order = []
while ready:
    u = ready.popleft()
    order.append(u)
    for v in graph[u]:
        indegree[v] -= 1
        if indegree[v] == 0:
            ready.append(v)
if len(order) == len(graph):
    print("Valid order:", order)
else:
    print("Cycle detected. Partial order:", order)
