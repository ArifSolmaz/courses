Kâğıt üzerinde izle

Boş beş yuvaya 7, 12, 17 kodlarını code mod 5 ve doğrusal yoklamayla yerleştir. Ardından 17’yi ve bulunmayan 22’yi ara. [7, 12, 17] sıralı tablosunda ikili aramayla karşılaştır.

Önce kendi izini yaz. Sonra adımları karşılaştır ve yöntemin neden işe yaradığını üç cümleyle açıkla.

İzi karşılaştır

Üçü de 2. yuvadan başlar. 2, 3 ve 4. yuvalara yerleşirler. 17 için üç, 22 için boş 0. yuvaya dek dört yoklama gerekir. Bu örnekte silme yok. Boş yuvalar gereklidir ve çakışmalar işi artırabilir.

Süreyi ölç

Tekrarlı tam eşleşme sorgularında hangi yöntemin hızlı olacağını tahmin et. İki boyutta ikili arama ile Python sözlüğünü ölç. Yapıları önce hazırla. Küçük denetleyici için bellek maliyetini ayrıca karşılaştır.

Çalıştır’a bas veya kodu Python 3’e kopyala. Çıktıdaki iki süre, beş grup ortalamasının medyanı ve en büyüğüdür. Her biri çağrı başına milisaniye cinsindendir. Gözlenen en büyük grup ortalaması tek bir çağrının üst sınırı değildir.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def lower_bound(values, key):
    lo, hi = 0, len(values)
    while lo < hi:
        mid = (lo + hi) // 2
        if values[mid] < key:
            lo = mid + 1
        else:
            hi = mid
    return lo

def exact_lookup(values, key):
    index = lower_bound(values, key)
    if index < len(values) and values[index] == key:
        return values[index]
    return None


for n in (100, 1000):
    values = list(range(n))
    table = {value: value for value in values}
    keys = [n // 2, n]

    def binary_queries():
        return [exact_lookup(values, key) for key in keys]

    def hash_queries():
        return [table.get(key) for key in keys]

    assert binary_queries() == hash_queries()
    measure(f"{n}: binary pair", binary_queries)
    measure(f"{n}: hash pair", hash_queries)
