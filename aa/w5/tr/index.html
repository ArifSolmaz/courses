Kâğıt üzerinde izle

Boş beş yuvaya 7, 12, 17 kodlarını code mod 5 ve doğrusal yoklamayla yerleştir. Ardından 17’yi ve bulunmayan 22’yi ara. [7, 12, 17] sıralı tablosunda ikili aramayla karşılaştır.

Önce kendi izini yaz. Sonra adımları karşılaştır ve yöntemin neden işe yaradığını üç cümleyle açıkla.

İzi karşılaştır

Üçü de 2. yuvadan başlar. 2, 3 ve 4. yuvalara yerleşirler. 17 için üç, 22 için boş 0. yuvaya dek dört yoklama gerekir. Bu örnekte silme yok. Boş yuvalar gereklidir ve çakışmalar işi artırabilir.

Çakışmayı ve başarısız sorguyu izle

2, 9 ve 16 anahtarlarını key mod 7 ve doğrusal yoklama ile yedi yuvaya yerleştir. 16’yı ve olmayan 23’ü ara. Daha önce silme yapılmadı.

Çözüm adımlarını göster
  1. Üçü de 2. yuvadan başlar. Sırasıyla 2, 3 ve 4. yuvalara yerleşirler.
  2. 16 için üç yuva incelenir. 23 için bunlara ek olarak boş 5. yuvaya bakılır.
  3. 9 silinip 3. yuva boş işaretlenseydi 16 araması erken dururdu. Silmeyi destekleyen bir tabloda silindi işareti veya kümeyi yeniden düzenleyen bir kural gerekir.

İki örneği karşılaştır. Bir sınır durumunu ve yanlış bir çözümü ele verecek bir işareti yaz. Ardından 10 dakika ara ver.

Süreyi ölç

Tekrarlı tam eşleşme sorgularında hangi yöntemin hızlı olacağını tahmin et. İki boyutta ikili arama ile Python sözlüğünü ölç. Yapıları önce hazırla. Küçük denetleyici için bellek maliyetini ayrıca karşılaştır.

Çalıştır’a bas veya kodu Python 3’e kopyala. Çıktıdaki iki süre, beş grup ortalamasının medyanı ve en büyüğüdür. Her biri çağrı başına milisaniye cinsindendir. Gözlenen en büyük grup ortalaması tek bir çağrının üst sınırı değildir.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def lower_bound(values, key):
    lo, hi = 0, len(values)
    while lo < hi:
        mid = (lo + hi) // 2
        if values[mid] < key:
            lo = mid + 1
        else:
            hi = mid
    return lo

def exact_lookup(values, key):
    index = lower_bound(values, key)
    if index < len(values) and values[index] == key:
        return values[index]
    return None


for n in (100, 1000):
    values = list(range(n))
    table = {value: value for value in values}
    keys = [n // 2, n]

    def binary_queries():
        return [exact_lookup(values, key) for key in keys]

    def hash_queries():
        return [table.get(key) for key in keys]

    assert binary_queries() == hash_queries()
    measure(f"{n}: binary pair", binary_queries)
    measure(f"{n}: hash pair", hash_queries)

Deney adımları

İlk 10 dakikada özgün kodu çalıştır, sonraki 20 dakikada girdileri değiştir ve son 15 dakikada bulguları karşılaştır. Başlangıç koduna dönmek için Örneği yükle düğmesini kullan.

  1. İki tam arama yöntemini çalıştır. Ölçmeden önce bulunan ve bulunmayan durumları ayır, dönüş değerlerini kontrol et.
  2. Sorguları önce dört eşleşme, sonra dört başarısız arama olacak şekilde değiştir. Aynı n ve sorgu sayısıyla yöntemleri karşılaştır.
  3. [0, 2, 4, 8] gibi boşluklu bir sıralı tabloda 5’i ara. İlk uygun indisin tam eşleşmede neden yalnızca aday olduğunu açıkla.
Kopyalanabilir deney kodu

Örneği yükle ile başlangıç koduna dön. Kodu düzenle, aşağıdaki parçayı kodun sonuna ekle ve Çalıştır’a bas.

values = [0, 2, 4, 8]
table = {value: value for value in values}
for key in (0, 5, 8, 9):
    result = exact_lookup(values, key)
    assert result == table.get(key)
    print(key, "->", result)

Teslim edilecek kayıt: tahmin, değiştirilen girdi, doğruluk kontrolü, süre ve sonucu açıklayan bir cümle.

Sabit arıza kodları için yöntem seç

Robot 120 arıza kodu saklıyor ve tabloyu yalnız başlangıçta güncelliyor. Tam kod sorgusu, sıralı liste ve bilinmeyen kod alarmı gerekiyor.

İlk 10 dakikada tek başına başla. 20 dakika eşinle çalış. Son 15 dakikada başka bir ekiple sonuçları karşılaştır ve önerini düzelt.

  1. Bulunamadı sonucu açık bir arayüz tasarla. Bulunan kod, arada olmayan kod ve en büyükten büyük kod için test yaz.
  2. Sıralı kod–ileti dizisiyle karma tablosunu karşılaştır. Kurulum, arama, bellek ve sıralı yazdırma maliyetlerini ayır.
  3. Hedef denetleyici için bir ölçüm tasarla. Zayıf karma dağılımını ortaya çıkarabilecek bir yük ve bellek tahmini yöntemi ekle.
Örnek çözümü karşılaştır

Sıralı dizi sıralı çıktı ve statik veride logaritmik arama sağlar. Karma tablosu tam sorguya uygundur, ancak ek alan ve çakışmalar uygulamaya bağlıdır. Bulunamadı sonucunu açık tanımla. Hedefte bulunan ve bulunmayan sorguları, en kötü gözlenen süreyi ve belleği karşılaştır.
