1. Çözümlü örnek — erken C’ye varınca devam et

Tepe adları farklı stringler, bütün komşular sözlük anahtarı; ağırlıklar sonlu tamsayılardır. steps negatif olmayan bir tamsayıdır. append bir seçimi ekler; dönüşte pop onu geri alır.

def enumerate_walks(graph, start, target, steps):
    if type(steps) is not int or steps < 0:
        raise ValueError("invalid steps")
    if start not in graph or target not in graph:
        raise ValueError("unknown endpoint")
    answers, trail = [], [start]
    def search(u, remaining, cost):
        if remaining == 0:
            if u == target:
                answers.append((trail.copy(), cost))
            return
        for v, weight in graph[u]:
            trail.append(v)
            search(v, remaining - 1, cost + weight)
            trail.pop()
    search(start, steps, 0)
    return answers

graph = {"A": [("B", 2), ("C", 3)],
         "B": [("A", 2), ("C", 2)],
         "C": [("A", 3), ("B", 2)]}
walks = enumerate_walks(graph, "A", "C", 3)
best = min((cost for _, cost in walks), default=None)

A–B–A–C toplamı 2+2+3=7. A–C dalı C’de hemen durmaz: A–C–A–C maliyeti 9, A–C–B–C maliyeti 7’dir. Bir dalın dönüşünde izi kopyalamak, sonraki pop işlemlerinin kaydedilmiş cevabı bozmasını önler.

2. Bir adımı sen tamamla

Yönsüz AB = 2, BC = 2, AC = 3 ağında A’dan başlayıp tam 3 bağlantı geçtikten sonra C’de biten kaç yürüyüş vardır? Sensöre yeniden uğramak serbest; erken C’ye varınca durulmaz. Bekleme ve öz-ilmek yoktur. Toplam maliyeti değil sayıyı yaz.

Önce tahminini yaz; gerekirse ipucunu aç.

İpucu

İlk adım B veya C’dir. Her dalı tam üç bağlantıya tamamla; yalnız son tepesi C olanları tut. A–C–A–C de geçerlidir.

Çözüm ve gerekçe — kendi hesabından sonra aç

3 yürüyüş. A–B–A–C (7), A–C–A–C (9), A–C–B–C (7). Parantezler maliyettir; yürüyüş sayısı değildir.

Matematik köprüsü — sayma, en iyiyi bulma ve çıktı boyutu

Her düğümde iki seçenek olduğundan bu üçgende k aktarım için 2ᵏ tam dal vardır; her biri C’de bitmez. Listeleme üstel büyüyebilir; her bulunan yürüyüşü kopyalamanın da maliyeti vardır. Burada çözüm sayısı 3, maliyetler 7,9,7, minimum 7: üç farklı sorudur.

n = 4
if not isinstance(n, int) or not 0 <= n <= 30:
    raise ValueError("Choose a whole number from 0 to 30")
ways = [0] * (n + 1)
ways[0] = 1
if n >= 1:
    ways[1] = 1
for step in range(2, n + 1):
    ways[step] = ways[step - 1] + ways[step - 2]
print("Table:", ways)
print("Number of routes:", ways[n])
