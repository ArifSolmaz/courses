Week 12 / 14 · Kruskal and spanning trees

How do we wire the stations at minimum cost?

15 min · Engineering question

The robot’s dock connects a controller and three sensors. Links have installation costs and work in either direction. We need every station connected with minimum total cable cost.

Read the concept and worked example first. Then make an individual prediction and compare it with a partner.

Connect every station using the least total cable

You will be able to

  • Distinguish a spanning tree from a route.
  • Sort candidate links by cost.

  • Interpret a disconnected result.

Before you start

A component is a set of stations already connected through accepted links. Initially each station is alone.

Kruskal examines links in increasing cost. Accept a link if it joins two different components, then merge those components. If the endpoints are already connected, adding the link would create a cycle. Track the accepted link costs, rather than the costs of all inspected links.

The cheapest way to connect components can be built by taking a least-cost link that joins two groups. A connected tree with n stations uses n − 1 links. If available links cannot connect all stations, the result is a spanning forest, one tree per component.

These three links connect all four stations. If CD is unavailable, D remains isolated and the forest’s total is only 5. That smaller number does not buy the required connectivity.

35 min

Trace it on paper

Sort the links AB:1, BC:2, AC:3, CD:4, BD:5. Start with four separate components. For each link, join its endpoints if they are in different components. Record accepted and skipped edges.

Write your trace first. Compare your steps, then explain why the method works in three sentences.

Check your trace

Accept AB and BC. Skip AC because A and C are already connected. Accept CD. Total 7 with three links. Kruskal chooses the cheapest available link that joins separate groups. Sorting links often dominates the work. A component structure tracks which stations are connected.

Compare a three-sentence explanation

Accept AB and BC to join A, B and C. Skip AC because its endpoints are already connected. Accept CD to connect D, for total cost 7.

Trace the effect of equal cable weights

Use links AB:1, AC:1, BC:1, BD:2 and CD:2. Trace Kruskal first with alphabetical ties, then with reverse alphabetical ties inside each weight.

Show the worked steps
  1. Alphabetical ties select AB, AC and BD. BC joins the same component and is skipped.
  2. Reversing ties selects BC, AC and CD. Both trees use three links and cost 4.
  3. To evaluate a proposal, check total cost, connectivity and absence of cycles. Equal cost can allow different layouts.

Compare the two traces. Record one boundary case and a clue that would expose a wrong result. Then take a 10-minute break.

Common mistakes

  • Choosing the cheapest three links without checking components.
  • Counting skipped links in the total.
  • Interpreting a forest as full coverage.

English–Turkish glossary

Spanning forest / Kapsayan orman
One tree for each disconnected group.

45 min

Measure it

Time Kruskal on small and larger networks with a chain plus extra links. Report accepted edges and total cost. Remove all links touching the last station and check the component count.

Select Run or copy the code into Python 3. The two times are the median and largest of five batch averages, in milliseconds per call. The largest batch average does not bound an individual call.

from statistics import median
from timeit import repeat


def measure(label, job, repeats=200):
    samples = repeat(job, repeat=5, number=repeats)
    typical = median(samples) * 1000 / repeats
    longest = max(samples) * 1000 / repeats
    print(f"{label:18}  {typical:.6f} ms  {longest:.6f} ms")

def kruskal(n, links):
    parent = list(range(n))
    size = [1] * n

    def root(node):
        while node != parent[node]:
            parent[node] = parent[parent[node]]
            node = parent[node]
        return node

    total = accepted = 0
    for cost, a, b in sorted(links):
        left, right = root(a), root(b)
        if left == right:
            continue
        if size[left] < size[right]:
            left, right = right, left
        parent[right] = left
        size[left] += size[right]
        total += cost
        accepted += 1
    return accepted, total, n - accepted


for n in (20, 200):
    links = [(1 + i % 5, i, i + 1) for i in range(n - 1)]
    links += [(4 + i % 7, i, i + 2) for i in range(n - 2)]
    print(n, "-> (accepted, total, components):", kruskal(n, links))
    measure(f"{n}: Kruskal", lambda: kruskal(n, links))
    isolated = [(cost, a, b) for cost, a, b in links if n - 1 not in (a, b)]
    assert kruskal(n, isolated)[2] == 2

45 min

Replan wiring around a blocked cable route

Four docks have links AB:1, AC:3, BC:2, BD:4 and CD:1. The BD link is an alternate corridor. A blocked conduit removes CD. The cable budget is 6.

Start individually for 10 minutes. Work with a partner for 20. Spend the last 15 comparing with another pair and revising your recommendation.

  1. Trace Kruskal before the blockage. List the chosen links, component count and cost.
  2. Remove CD, rerun and compare the new result with the budget. Next remove BD too and describe the output.
  3. Explain whether a minimum spanning tree provides redundancy and what extra requirement would change the planning problem.
Compare a model answer

Initially AB, CD and BC cost 4. Without CD, AB, BC and BD cost 7 and exceed the budget. Removing BD as well isolates D, leaving a two-component forest. A tree has a single path between any two vertices, so a redundant layout must permit extra links and include a failure criterion.

25 min

Exam-style questions

Spend 15 minutes on the three questions and two of the extra drills without help. Use the last 10 to check answers and rewrite one explanation.

  1. Why skip AC?

    Show answer

    A and C already have a path. Adding AC creates a cycle.

  2. What if D is isolated?

    Show answer

    There is no spanning tree. Kruskal returns a forest.

  3. Will the tree minimize travel distance from A to every station?

    Show answer

    No. It minimizes the total installed link cost.

More practice

  1. How many edges in a tree of four stations?

    Show answer

    Three.

  2. What is the accepted total?

    Show answer

    1 + 2 + 4 = 7.

  3. Can equal-cost links lead to different answers?

    Show answer

    Yes. Different trees can have the same minimum total.

  4. What does the component test tell you before accepting an edge?

    Show answer

    Whether the endpoints are already connected.

  5. How many edges does a forest with 10 stations and 3 components have?

    Show answer

    7.

5 min

Exit ticket

Why is a cheap forest with two components insufficient when every station must remain connected?

Write two or three sentences on your own. Support your answer with a count, a measurement or a step from today’s trace.

Compare a sample exit answer

Two components contain stations that cannot reach each other. The cost covers only connections inside the components. Connecting every station requires one component or a report that full coverage is impossible.
