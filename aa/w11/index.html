1. Çözümlü örnek — B’den gelen teklif C’yi iyileştirir mi?

Tepe adları farklı stringlerdir; bütün komşular sözlük anahtarıdır. Başlangıç mevcut olmalı; ağırlıklar sonlu, negatif olmayan tamsayılardır. Yönsüz bağlantıları iki yönde yazıyoruz. Min-öbek, en ucuz bekleyen teklifi verir.

import heapq

def dijkstra(graph, start):
    if start not in graph:
        raise ValueError("unknown source")
    if any(w < 0 for edges in graph.values() for _, w in edges):
        raise ValueError("negative weight")
    distance = {v: float("inf") for v in graph}
    parent = {v: None for v in graph}
    distance[start] = 0
    queue = [(0, start)]
    while queue:
        cost, u = heapq.heappop(queue)
        if cost != distance[u]:
            continue
        for v, weight in graph[u]:
            candidate = cost + weight
            if candidate < distance[v]:
                distance[v] = candidate
                parent[v] = u
                heapq.heappush(queue, (candidate, v))
    return distance, parent

graph = {"A": [("B", 2), ("C", 3)],
         "B": [("A", 2), ("C", 2)],
         "C": [("A", 3), ("B", 2)]}
distance, parent = dijkstra(graph, "A")

A işlenince B’ye 2, C’ye 3 teklif edilir. B’nin C’ye teklifi 2 + 2 = 4; mevcut 3’ten küçük olmadığı için kayıt değişmez. Son uzaklıklar A:0, B:2, C:3. Eski öbek kaydı güncel uzaklığa eşit değilse atlanır; eşit maliyetli teklif ebeveyni değiştirmez.

2. Bir adımı sen tamamla

Aynı yönsüz ağda AB = 2, BC = 2, AC = 3. A’dan C’ye en düşük toplam yol maliyeti kaçtır? MST’nin toplamını veya kenar sayısını yazma.

Önce tahminini yaz; gerekirse ipucunu aç.

İpucu

A–C doğrudan yolunu ve A–B–C yolunu karşılaştır. Sadece MST’de seçilmiş kablolarla sınırlı değilsin.

Çözüm ve gerekçe — kendi hesabından sonra aç

3 maliyet birimi. Doğrudan AC = 3; B üzerinden 2 + 2 = 4. C’nin ebeveyni A olur. MST toplamı 4 farklı bir sorunun cevabıdır.

Matematik köprüsü — “gevşetmek” hangi sayıyı değiştirir?

d[v] ← min(d[v], d[u] + w): v için mevcut en iyi teklif ile u üzerinden yeni teklifi karşılaştır; küçüğünü sakla. d[v], henüz sonuçlanmadan önce son minimumu garanti etmez. Dijkstra’da negatif olmayan ağırlıklar en küçük güncel teklifin kesinleşmesini sağlar. Hafta 8’deki BFS eşit pozitif ağırlıklarda yeterlidir. Hafta 9’daki topolojik sıra ise DAG’da, negatif ağırlıklar olsa da kenarları sırayla gevşetmeye izin verir.

3. Yeni durumda kendin karar ver

C’nin bütün bağlantıları koparsa ne döndürmelisin? Sıfır maliyetli kenar Dijkstra’yı bozar mı? Negatif ölçüm girilince kodun neden sonuç vermemesi gerekir?

Kendi açıklamanı denetle

C tanımlı fakat erişilemezse uzaklığı ∞, ebeveyni None kalır; 0 veya bir yol uydurulmaz. Sıfır ağırlık geçerlidir. Kod, erişilmeyen bölümdekiler dahil her negatif kenarı baştan reddeder. Bu yönsüz ağda negatif kenarda gidip gelmek toplamı sınırsız azaltabilir; en kısa yürüyüşün sonlu minimumu kalmaz.

Mevcut Dijkstra Python laboratuvarı yönlü A→B=2, A→C=5, B→C=1 girdisini kullanır; buradaki yönsüz üçgenle aynı girdi değildir.

Çıkış ölçütü: yol toplamını, gevşetmeyi ve önkoşulu açıklayabiliyorsan alt problemlere geç. Takıldıysan Dijkstra’nın seçim sırasını izle; bu görsel de yönlü 2,5,1 örneğidir.
